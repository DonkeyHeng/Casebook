# 衡算报告(怎么用 · 数字怎么来的)

> 方案与口径依据见 [`balance-report-plan.md`](balance-report-plan.md)。
> 本文件只讲**怎么用**和**哪些数字不能当真**。

---

## 1. 从哪进

**网页**:侧栏「衡算报告」页:

1. 上半页是工段边界:每段两个输入框,左边「进界流股」、右边「出界流股」,逗号或空格分隔。
   默认填的是按设备名段号推出来的草稿,标签旁会写「当前是自动草稿,未人工确认」;
2. 改完点「保存工段边界」→ 写进 `data/config/sections.json`,之后左上角提示变成「已载入人工确认结果」;
   点「重置为草稿」可以丢掉本次编辑;
3. 下半页勾要核算的设备(可按家族一键批量,不勾 = 全部);
4. 点「生成衡算报告(.docx)」下载。

**命令行**(无界面 / 批量):

```bash
python -m tools.balance_report --list                      # 先看有哪些工况
python -m tools.balance_report --case 40                   # 全流程
python -m tools.balance_report --case 40 --families mix,column
python -m tools.balance_report --case 40 --blocks E0101,T0202
python -m tools.balance_report --case 40 --out D:/reports   # 换个落盘目录
```

文件默认落在 `data/preview/`,名字形如 `Casebook_case40_balance_20261114-135729.docx`。

## 2. 报告结构

```
封面         标题 + 工况 + 读取时间 + Aspen 版本 + 收敛判定 + 流股/设备数
校核结论摘要  一段总判语 + 质量守恒状态表 + 焓平衡状态分布表 + 能量汇总一句话
一、物料衡算  1.1 工段界区衡算(每工段一张) → 1.2 逐设备质量守恒(每设备一张)
二、能量衡算  2.1 逐设备能量表(换热器分冷/热两行)→ 2.2 全流程汇总 → 2.3 塔负荷明细
附注         数据来源、基准与单位、容差、塔负荷来源、口径边界、非工程设计依据
```

表题全文连续编号(表 1、表 2…),三线表,数字取整:质量/摩尔/功率/压力 2 位、
温度 1 位、相对误差 3 位(%);**空值留空,不写 0**。

## 3. 工段边界怎么确认

工段是**界区**:一组进界流股 + 一组出界流股,界区衡算 `Σ进 = Σ出`。
工具能按设备名段号(如 `E0101` → 01 段)自动推一版草稿,实测 9 个工况全部闭合;
但跨段接口设备会让草稿出现怪项,所以要人工过一遍。

1. 复制样例:`samples/sections.example.json` → `data/config/sections.json`
2. 按**工况 id** 填 `in`(从界区外进来)/ `out`(从本工段出去)的流股名
3. 可选:`label` 改成工艺名称(报告小节标题就用它)、`device_sections` 修正某台设备的归堆

```json
{
  "40": {
    "01": {"label": "第一工段", "in": ["FEED-A"], "out": ["1TO2", "FW-0101"]}
  }
}
```

`in` / `out` 改成空列表是**有效决定**(表示该段没有跨界流股),不会回退到草稿。
配置按工况 id 存,所以在 `data/config/`(不入库),换机器要重新确认。

## 4. 数字不能当真到什么程度

| 结论 | 依据 | 限制 |
| --- | --- | --- |
| 界区质量守恒 | `Σ进界 = Σ出界`,相对误差 ≤ 0.5% 判通过 | 边界流股靠人确认;自动草稿可能把跨段设备算进本段 |
| 逐设备质量守恒 | `Σ进口 = Σ出口`,同容差 | 单进单出设备恒等、误差恒为 0,信息量在 Mixer / FSplit / 塔 / 换热器 |
| 焓平衡 | 直接引库内已有结论(`blocks.balance_state`) | 不重算;塔与反应器按约定「不校验」 |
| 能量汇总 | 正 duty + 塔再沸器 / 负 duty + 塔冷凝器 / 轴功率 | 反应器的 QCALC 是反应热,不计入总量,单独一行 |
| 塔负荷 | 块字段 `COND_DUTY/REB_DUTY` 优先,缺失用逐级剖面首/末级 | 部分冷凝器的塔,首级可能不等于冷凝器总负荷 |

**实测规模**:9 个工况 / 653 台设备,逐设备相对误差最大 0.005058%、
界区最大 0.0040%,**0 台越界**。也就是说真实数据里没有「真漏流股」的样本,
「超差标红」只在自测夹具里验证过 —— 这条限制写进了报告附注。

`相对误差` 不区分「漏流股」与「求解器残差」:量级小是正常收敛误差,
量级大(10% 以上)才值得查模型。

## 5. 自测

```bash
python -m tools.selftest                        # 全离线,不需要 Aspen
python -m tools.selftest --db data/cases.db     # 再核库内结论与规则一致
```

`能量衡算 energy_report`、`衡算报告 report_export`。阳性夹具在
`samples/case-23-error.db` 的副本上运行时删一条连接造出来,不新增二进制样本。
