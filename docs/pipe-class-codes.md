# 管道等级号规则(HG/T 20519.6)+ 本项目约定

> 来源:用户提供的规则整理(`管路选型/新建 文本文档.txt`),2026-11-01 定稿。
> 管路选型功能按本文件生成等级号;**标准 PDF 不入库**(见 `.gitignore`),规则摘要在这里。

## 1. 等级号结构

```
[压力代号] + [顺序号 1~9] + [材质代号]
例:Q1E、M1E、H2B、L1E
```

## 2. 压力等级代号(国内常用)

| 代号 | 公称压力 MPa |
| --- | --- |
| H | 0.25 |
| K | 0.6 |
| L | 1.0 |
| M | 1.6 |
| N | 2.5 |
| P | 4.0 |
| Q | 6.4 |
| R | 10.0 |
| S | 16.0 |
| T | 20.0 |
| U | 22.0 |

> ASME 美标代号(本工具不用):A=150LB、E=900LB、F=1500LB、G=2500LB。

## 3. 顺序号(数字 1~9)

同压力、同材质下细分系列号(区分温度/法兰垫片配置),**无强制含义,项目自编**。本工具默认固定为 `1`。

## 4. 材质类别代号

| 代号 | 材质类别 | 本项目对应 |
| --- | --- | --- |
| A | 铸铁 | — |
| **B** | 碳钢 | 20# |
| **C** | 普通低合金钢 | 16Mn(查许用应力按 Q345B) |
| D | 合金钢 | 铬钼钢等 |
| **E** | 不锈钢 | S30408 / S31603 |
| F | 有色金属 | 铜、铝 |
| G | 非金属 | PVC、FRP |
| H | 衬里/内防腐 | 衬 PTFE、衬胶 |

## 5. 绝热代号(编号末尾)

| 代号 | 含义 |
| --- | --- |
| H | 保温 |
| C | 保冷 |
| P | 人身防护防烫 |
| T | 伴热 |

本工具口径(2026-11-01 定):**≥50 ℃ → `-H`**;其余不加;C/P/T 需人工勾选。

## 6. 报告里可直接用的说明段落

> 管道材料等级号依据 HG/T 20519.6 编制,由压力等级代号、材料顺序号、材质类别代号三段组成:
> 首字母为公称压力代号,数字为同压力同材质下的系列顺序号,末字母为材质类别
> (B 碳钢、C 低合金钢、E 不锈钢)。绝热代号:H 保温、C 保冷、P 防烫、T 伴热。

## 7. 与本项目两份外部资料的差异(实测,写报告时注意)

| 表 | 末字母 × 管材 | 是否符合本规则 |
