# 管道等级号规则(HG/T 20519.6)+ 本项目约定

> 来源:用户提供的规则整理(`standards/HG-T-20519.6-管道等级号规则.txt`),2026-11-01 定稿。
> 管路选型功能按本文件生成等级号;**标准 PDF 不入库**(见 `.gitignore`),规则摘要在这里。

## 1. 等级号结构

```
[压力代号] + [顺序号 1~9] + [材质代号]
例:Q1E、M1E、H2B、L1E
```

## 2. 压力等级代号(国内常用)

| 代号 | 公称压力 MPa |
| --- | --- |
| H | 0.25 |
| K | 0.6 |
| L | 1.0 |
| M | 1.6 |
| N | 2.5 |
| P | 4.0 |
| Q | 6.4 |
| R | 10.0 |
| S | 16.0 |
| T | 20.0 |
| U | 22.0 |
| **V** | **真空管路(项目扩展,2026-11-18)** |

> V 不是 HG/T 20519.6 标准压力代号:操作绝压 < 95.0 kPa(表压 < −6.3 kPa)的流股
> (含 91.3 kPa 微负压、10 kPa 及以下的深真空)以前落 H1E,与高压 H(0.25 MPa)混淆,
> 现统一用 **V1E**(见 `pipe-selection-plan.md` §17.1 / §19.1)。
> `1 bar = 100 kPa` 的常压流股不再判真空。
> V 管按外压失稳校核壁厚,不与 PN 表比大小,校验 V4 对 V 放行。
>
> ASME 美标代号(本工具不用):A=150LB、E=900LB、F=1500LB、G=2500LB。

## 3. 顺序号(数字 1~9)

同压力、同材质下细分系列号(区分温度/法兰垫片配置),**无强制含义,项目自编**。本工具默认固定为 `1`。

## 4. 材质类别代号

| 代号 | 材质类别 | 本项目对应 |
| --- | --- | --- |
| A | 铸铁 | — |
| **B** | 碳钢 | 20#、Q235 系列 |
| **C** | 普通低合金钢 | 16Mn(查许用应力按 Q345B)、Q345 系列 |
| D | 合金钢 | 铬钼钢等 |
| **E** | 不锈钢 | S30408 / S31603 / 321 / 双相钢 |
| F | 有色金属 | 钛(TA2)、铜、铝 |
| G | 非金属 | PVC、FRP |
| H | 衬里/内防腐 | 衬 PTFE、衬胶 |

**牌号怎么落到代号**(`pipe_data.material_code_for()`):

1. `MATERIAL_CODE_BY_GRADE` 里已确认的表 B.1 牌号直接取映射(2026-11-23 逐个确认 104 个:A 铸铁 8、B 碳钢 25、C 普通低合金钢 22、D 合金钢 38、E 不锈钢 11);
2. 表 B.1 之外的牌号才按前缀给建议值:`S1/S2/S3 加五位数字`、`0Cr18Ni9` 这类 → E;`Q235`、`10#`、`20#`、`20G` → B;
   `Q345`、`16Mn` → C;`TA2`、`Ti` → F;`PVC/PP/PTFE` → G;
3. 表外牌号都判不出来(含未确认的铬钼耐热钢)→ 等级号末字母按 `E` 暂记,并在该行给出「类别无法判定,待人工确认」的提示。

可选牌号**跟着已录入的表 B.1 走**:表里有什么牌号(含 `06Cr19Ni10(304)` 这类写法,已归一到 `S30408`),
下拉里就能选什么;表没录时才退回 5 个预置牌号。

## 5. 绝热代号(编号末尾)

| 代号 | 含义 |
| --- | --- |
| H | 保温 |
| C | 保冷 |
| P | 人身防护防烫 |
| T | 伴热 |

本工具口径(2026-11-18 第二轮修订,见 `pipe-selection-plan.md` §18.3):
**保温按设计温度 ≥ 65 ℃ → `-H`**(设计温度 = 操作温度 + 20 ℃,即**操作 ≥ 45 ℃**);
≤ 0 ℃ → `-C`;其余不加;P/T 需人工勾选。2026-11-01 的"≥50 ℃"口径已废止
(25–45 ℃ 常温管线曾被误判包保温)。


## 6. 报告里可直接用的说明段落

> 管道材料等级号依据 HG/T 20519.6 编制,由压力等级代号、材料顺序号、材质类别代号三段组成:
> 首字母为公称压力代号,数字为同压力同材质下的系列顺序号,末字母为材质类别
> (B 碳钢、C 低合金钢、E 不锈钢)。绝热代号:H 保温、C 保冷、P 防烫、T 伴热。

## 7. 与常见写法的差异(写报告时注意)

本工具**以本规则为准**自动生成等级号:压力代号 + 顺序号 + 材质类别字母。

实际项目里常见两类不一致:①末字母与管材类别对不上(如不锈钢写成 `B`);②高温段漏加 `-H`。
导出表里遇到这类行会标黄,理由写「等级号末字母与材质类别不符 HG/T 20519.6」或「疑似漏标绝热代号」。
