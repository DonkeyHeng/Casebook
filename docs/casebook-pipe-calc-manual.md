## 1 适用范围与计算链

本说明书描述 Casebook「管道」页对一条 Aspen 流股做管路选型的完整算法：需要哪些输入、按什么顺序算、每个系数从哪里来、哪些情况不计算。只解释口径，不代替 GB/T 20801.1-2025（该版已把原第 1–6 部分中的工业管道内容合并为一部（另设第 5 部分《氢用管道》），材料许用应力与设计规则同在此部）、GB/T 17395 原文，也不代替设计院的强度与应力审核。

算法由四层叠加，复算时请分开核对：标准公式层（承压与尺寸序列）、工程判据层（最小壁厚、真空、两相、汽蚀等阈值）、人工参数层（流速、材质、腐蚀裕量）、校核层（V1–V15 只读检查，不参与计算；V14 未实现）。工程判据层的阈值集中写在代码常量表里（位置见附录 A），是可配置常量而不是标准原文，说明书中逐条注明。

**表 1-1 计算链总览**

| 步骤 | 做什么 | 落到输出 |
| --- | --- | --- |
| S0 | 三张标准表就绪检查；剔除热流、功流等非物料流股 | 可算流股集合 |
| S1 | 体积流量门槛：缺失或 ≤ 0 直接不选型；0 < Q ≤ 0.01 m³/h 单列待人工确认 | missing 列表 / flagged 清单 |
| S2–S4 | 相态、介质代号、目标流速（含泵入口与汽蚀修正） | phase / 代号 / v |
| S5 | 按目标流速算内径；两相另加动压头限速与液相下限 | Di |
| S6–S7 | 设计压力、设计温度 | Pd / Td |
| S8 | 材质 S30408/S31603 且操作绝压 4.7–6.4 MPa → 强制 R；6.4 < Pd ≤ 10.0 MPa 自然落 R 档同样走 R1E；Pd >10.0 MPa 守卫关闭；温度不作硬门槛 | hp_formula / force_code；缺温度时等级号仍 R1E，壁厚走 S8a 退化，升档标记与 V13 只看自然档 |

## 2 输入与单位

### 2.1 流股读数

读数来自当前工况快照（读取时已按 Aspen 节点自带的单位串换算），计算不实时回读 Aspen。

**表 2-1 参与计算的流股字段及缺值行为**

| 字段 | 含义 | 单位 | 在本算法中的作用 | 缺值 / 异常行为 |
| --- | --- | --- | --- | --- |
| name | 流股号 | — | 主键、编号主体、泵进出的拓扑键 | 缺失则不进入选型 |
| temperature_c | 操作温度 | ℃ | 设计温度、保温判定 | 缺失时保留几何 DN，但 Td、σ、壁厚为空；报 warn「缺操作温度，无法计算设计温度与壁厚」 |
| pressure_bar | 操作压力（绝压） | bar | 设计压力、真空判定、汽蚀判定 | 缺失或 ≤0/非有限值：不计算 Pd、壁厚与等级号；详见 4.1 节与表 7-2 |
| vol_flow_m3h | 体积流量 | m³/h | 内径、流速、两相密度 | 缺失或 ≤0 进入 missing 列表不选型；0<Q≤0.01 单列待人工确认，不给 DN 与壁厚 |
| mass_flow_kgh | 质量流量 | kg/h | 只用于两相 ρm = m/Q | 两相下缺失或 ≤0：跳过动压头限速，按两相流速选径并报 warn；单相不使用 |
| vap_frac | 汽化率 | — | 相态判定的唯一依据 | 缺失时暂按液相选型并报 warn「缺汽化率，暂按液相选型，请复核」，不是已确认单相 |
| stream_type | 流股类型 | — | MATERIAL 才参与选型 | 热流、功流等非物料流股剔除，不选型 |

> **注：** 压力的两种用法要分开：真空判定与汽蚀区间按绝压使用，只做 bar × 100 = kPa，不减大气压（见 2.5 节）；计算设计压力时按第 4.1 节先减 0.1013 MPa 换成表压，再按倍率、附加项与下限取大，详见第 4.1 节。质量流量不用于 m³/h 换算：体积流量缺失时直接判「未选型」，不反算。压力缺失、≤0 或非有限值的完整后果见 4.1 节与表 7-2。读取层只收绝压单位串：bar、atm、Pa、kPa、MPa、psi/psia、mmHg/torr、kgf/cm²；psig、barg、kPag、MPag、psid、bard 等表压或差压单位串查不到换算 key，pressure_bar 直接留空，随即走 4.1 节的空值路径并触发 V15，不按「表压 + 1 atm」自行折算成绝压。这条读取边界与《泵计算说明书》2.1 节同源。

### 2.2 由拓扑派生的三个集合

设备—流股连接关系（connections）与设备类型（blocks）派生出以下集合，它们只影响选流速、限速与内径下限，不改压力与温度。

- pump_in：进入泵的流股，按泵入口流速 0.8 m/s 选径；按拓扑判定，不分相态（气相、两相进口同样取 0.8 m/s）。

- pump_out：泵产出的流股，单独参与 V8（既是入口又是出口的错接检查），且禁止按汽蚀把流速往 0.8 m/s 压。

- pressurized：明显升压线，与 pump_out 取并集；判据见下式。该并集只在汽蚀限速门控中生效，不进入 V8。

> \|Q − Q_f\| ≤ 0.02·max(Q, 1e-9) 且 \|t − t_f\| ≤ 2 ℃ 且 p > p_f + 0.5 bar
>
> 升压线判据：存在一条上游进料 f 同时满足流量、温度接近与压力升高

该判据不只服务泵：对用非泵模块模拟的液体近等温升压拓扑也作兜底；pump_out 与它取并集，所以泵出口即使不满足压差判据，也仍按泵出口处理，不会被误当成可放大管径的吸入侧。并集只用于排除汽蚀限速；V8 不读取这个并集，只看行上的 pump_outlet / pump_inlet 标记是否同时为真。

## 3 选径

### 3.1 相态判定

> x ≤ 1×10⁻⁴ → 液体 ； x > 1 − 1×10⁻⁴ → 气体 ； 其余 → 气液共存
>
> x 为汽化率；用容差而非等于 0，因为实测有 1e-8 量级的痕量汽化率。边界取等号：恰为 1×10⁻⁴ 按单相，泵侧照算 NPSHₐ、读取层按 m/V 取密度；超过 1×10⁻⁴ 才按两相。气相边界是严格大于：恰为 1−1×10⁻⁴ 仍按气液共存。该容差是全局唯一常量 TWO_PHASE_VAP_EPS = 1×10⁻⁴：管道相态、泵 NPSHₐ 门禁与读取层的密度口径共用它（《泵计算说明书》第 2、4、7 章为同一取值）

缺汽化率时仍暂按液相选型（不阻断选径），但必须报「缺汽化率，暂按液相选型，请复核」；这是待复核状态，不是已确认单相。

### 3.2 介质代号

液体 PL、气体 PG、气液共存 PGL，代号可按相态覆盖，用于管路编号前缀。

### 3.3 目标流速与汽蚀修正

**表 3-1 目标流速**

| 相态 | 选取值 m/s | 推荐区间 m/s |
| --- | --- | --- |
| 液体 | 1.5 | 1.0–2.5 |
| 气体 | 15.0 | 10.0–25.0 |
| 气液共存 | 8.0 | 5.0–10.0 |
| 泵入口（不分相态） | 0.8 | 0.5–1.0 |

液相且接近沸点时把流速压到 0.8 m/s 以内，条件是**闭区间**同时满足 80 ≤ t ≤ 105 ℃ 与 95 ≤ p ≤ 115 kPa（两端都取等号，按 kPa 比较），且该流股不是泵入口、不是泵出口、也不在升压线上。泵入口按拓扑判定、不分相态，恒取 0.8 m/s（气相、两相进口也如此）；因此若气相或两相流股被拓扑误判成泵入口，按 0.8 m/s 选径会显著偏大，必须核查泵进出口拓扑与流股方向；升压线严禁按吸入侧放大。

> v = min(v₀, 0.8) （近沸点液体且非泵入口、非泵出口、非升压线）
>
> 汽蚀限速（近沸点液体，且非泵入口、非泵出口、非升压线）

> **注：** 80–105 ℃ / 95–115 kPa 是常压水体系的经验判据（水的常压沸点附近）。非水介质（有机溶剂、酸碱、低温冷媒）或加压/减压体系的泡点压力与这一区间无关，不能自动套用，必须按实际泡点压力人工复核；复核后如需放宽，按 2.3 节的参数口径改目标流速，而不是改这一判据区间。

### 3.4 计算内径

> Di = 1000 · √( 4·(Q/3600) / (π·v) ) [mm]
>
> Q 为 m³/h，v 为 m/s，结果 mm

### 3.5 两相流的两个额外限制

> ρm = m / Q ； v_lim = √(2000 / ρm)
>
> 均相动压头 ρv² ≤ 2000 Pa 反解流速上限；m 取 kg/h、Q 取 m³/h 时 ρm 量纲即 kg/m³
>
> Di = max( Di, 1000·√(4·(Q/3600)/(π·v_lim)) )
>
> 按限速重算内径，取二者较大值

第二条限制：两相流的内径不得小于「产出它的设备」的纯液相进料内径的最大值。比较的是各流股选档前的计算内径 Di（不是选档后的实际内径）；先完成全部流股首轮计算内径 Di，再对命中下限的两相流股抬高 Di，并统一重算其后续选档与壁厚，而不是只补丁单行。两相但质量流量缺失或 ≤0 时，ρm 无法求得，跳过 ρv² ≤ 2000 Pa 的动压头限速，仍按两相目标流速选型，并必须给出「缺质量流量，未执行两相动压头限速校核」告警；不得把「没校核」静默当成「已满足」。

上游液相内径下限的边界提醒：该下限取产出设备所有纯液相进料内径的最大值。带微小侧线的闪蒸罐/分离器要特别注意：若设备还有主液相进料，两相出口会被主进料内径抬高；若拓扑里只看微小侧线，又会低估所需管径。选型前应核对设备进料拓扑，不能把侧线的细管径直接当主管设计依据。多流股换热器（如 HeatX）也有同类风险：冷热程进料共用同一设备拓扑，可能把另一程的大流量液相进料内径传导到本程两相出口；选型前须同时核对两程进料。

### 3.6 DN 选档

把可用 DN 升序试一遍（先剔除 65 与 125，跳过小于 DN15 的档），取第一个满足「实际内径 ≥ 计算内径」的档；壁厚在试算时同步求，见第 5 章。缺壁厚或许用应力时，不能拿外径直接当内径，也不能因此放宽档位；退化判据为 Do − 2×工艺最小壁厚(dn) ≥ Di（Do 即外径、Di 即计算内径；工艺最小壁厚见第 5.3 节），壁厚仍返回空，并继续遵守 DN10 / DN65 / DN125 的跳过规则。缺操作温度时，普通路径与 R1E 路径都按本退化给几何 DN；R1E 查不到 [σ]^t 的早退条件与例外见 5.4.3 节，此处不展开。

人工覆盖口径：pipe_run 的 dn_override 与自定义外径/壁厚由公共合并层统一生效，管道页、导出表与校核使用同一份生效行；生效范围、壁厚重算与 V2/V3 校核见 9.3 节。普通行与 R1E 行的 t_required_mm 语义不同，不可直接横向比较，见 5.4.2 节。泵侧对应说明见《泵计算说明书》9.1 / 9.4 节。

```text
for dn in 升序(DN 序列):
    if dn in (65, 125) or dn < 15: continue
    Do = DN_TO_OD[dn]
    可算壁厚 = 压力、温度、许用应力、标准壁厚序列均具备 且 t_c < Do/6
    S = 圆整壁厚(Do) if 可算壁厚 else None
    if S is not None: 判据内径 = Do − 2S
    else: 判据内径 = Do − 2·工艺最小壁厚(dn)   # 仅几何估算
    if 判据内径 ≥ Di: 选定 dn，停止（缺壁厚时 wall_mm 仍为 None）
```

全部档位都试不通时，只有计算内径落在 DN1000 的 动态容差带 内才允许取 DN1000。容差带以该档实际圆整壁厚 S 算出的内径 d_act = Φ1016 − 2S 为基准，区间为 (d_act, 1.05×d_act]；超径百分比也以 d_act 为分母，不是固定按 996 mm 算。没有壁厚数据时退化用最小壁厚 10 mm，即 d_act = 996 mm，此时才回到 996–1045.8 mm 的口径（1.05×996 = 1045.8）。容差判据只在最后一档使用；更大内径判「需并联或专项设计」。外径 Do > 630 mm 且表里没有该外径的壁厚数据时，按 HG/T 20553-2011 表 2.0.2-2 的 Ia 采购档兜底：DN700/800/900 取 6.3 / 7.1 / 8 / 8.8 / 10 / 11 / 12.5 / 14.2 / 16 / 17.5 / 20 mm；DN1000 无 6.3、7.1，从 8.0 起。该序列不含 18 mm 等非标档，并提示按采购规格复核。

## 4 设计压力、设计温度与材质

### 4.1 设计压力

> P_表 = P_绝(MPa) − P_atm ； Pd = max(0, K_p·P_表, P_表 + ΔP_add, P_floor) [MPa(G)]
>
> 非真空流股；默认 P_atm = 0.1013 MPa、K_p = 1.15、ΔP_add = 0.15 MPa、P_floor = 1.0 MPa

95–101.3 kPa 的表压为负：max 里的 0 只保证不出现负设计压力，不改变兜底档位——默认下限 1.0 MPa 会先把这一段抬到 1.0 MPa（压力代号 L），只有把附加项与下限都设为 0 时才落到 0 MPa（压力代号 H，常规情形下壁厚由最小壁厚控制）。

绝压低于 95 kPa 判为真空：设计压力固定取 0.1 MPa，真空默认压力代号用 L（PN10，1.0 MPa；按工程最低压力等级配级）；真空身份由布尔字段 is_vacuum 独立识别，不依赖等级号字母前缀。壁厚由最小壁厚与外压筛查控制，不按 PN10（1.0 MPa）内压整档保护。V 在 HG/T 20519-2009 中表示 PN250（25.0 MPa）高压，本项目真空不占用该代号。

> P_绝 < 95 kPa → Pd = 0.1 MPa，真空代号 L，is_vacuum = True
>
> 真空判定；代号只表示 PN10（1.0 MPa）配级，算法按 is_vacuum 走外压路径

压力缺失与非法值不兜底：pressure_bar 为空、≤ 0 或不是有限数值时不计算设计压力；整行仍按 3.6 节退化给几何 DN，既不把缺压力静默算成 0 MPa 的 H1E，也不把 0 或负压伪装成真空 L1E。逐字段的空值与错误文案、V15 口径统一见 7.1 节表 7-2。

Pd > 22.0 MPa 时超出内置 PN 代号表：仍保留输出行、按实际设计压力计算壁厚，但等级号返回空，并提示「超出 PN 代号表，未吃 PN 保护，需专项设计」；不得用某个相邻 PN 档冒充满足。

### 4.2 设计温度与绝热后缀

设计温度按操作温度的符号取裕量方向：t ≥ 0 ℃ 时 Td = t + 20 ℃，t < 0 ℃ 时 Td = t − 20 ℃，即裕量永远落在更危险的一侧（低温侧要更冷）。裕量可经 design_temp_margin 关闭。绝热后缀按设计温度判定：≥ 65 ℃ 加 -H（保温），≤ 0 ℃ 加 -C（保冷）；防烫 -P 与伴热 -T 不自动判定，需人工填。

> Td = t_操作 + ΔT_m（t ≥ 0）； Td = t_操作 − ΔT_m（t < 0）
>
> 设计温度；默认 ΔT_m = 20 ℃；低温段取偏冷侧，否则 -C 与 V7 会被整体抬高 20 K 而漏判。低温段对称取 −20 ℃ 是偏保守的简化策略，不是标准强制规定；如有项目规定的低温裕量，应按项目规范覆盖。

0 ℃ 附近要注意：t < 0 ℃ 时 Td = t − 20 ℃，所以操作 −0.1 ℃ 会直接得到 −20.1 ℃，同时落入 V7（设计温度 < −20 ℃）并加保冷 -C。若该工况并非真实低温，需人工复核是否应关闭裕量或改小裕量；代码对裕量数值本身不做范围校验。

缺操作温度时保留几何 DN，但不计算设计温度、许用应力与壁厚；等级号仍可按设计压力给出，但不含绝热后缀。告警只报一条「缺操作温度，无法计算设计温度与壁厚」，不重复报「缺许用应力」；逐字段口径见 7.1 节表 7-2。

### 4.3 材质、腐蚀裕量与许用应力

材质优先级：逐流股人工指定 > 管道等级表命中规则 > 全局默认 S30408。腐蚀裕量 C2 同序：等级表规则 > 内部 options（corrosion_mm）> 按材质兜底（20# 取 1.0 mm，其余 0）。材质以 S3 开头时用表 4 的壁厚序列，否则用表 1。

许用应力按设计温度在表 B.1 中查：低于表内最低温度取最低档，高于最高温度返回空（不猜蠕变段），落在两档之间线性插值；预置牌号按固定「标准 + 牌号」取行：20# 取 GB/T 8163 的 20# 行，Q345A 取 GB/T 8163 的 Q345A 行，Q345B 取 GB/T 6479 的 Q345B 行（三个尺寸档取最小值），S30408 取 GB/T 14976 的 06Cr19Ni10（304），S31603 取 GB/T 14976 的 022Cr17Ni12Mo2（316L）；仅表外牌号才在同牌号多行间按各温度取最小值。查不到许用应力时，选档退化为按 Do − 2×工艺最小壁厚(dn) 估算几何内径（Do 即外径，工艺最小壁厚见第 5.3 节，不是强度计算壁厚），壁厚留空并给出缺项提示；仍跳过 DN10 / DN65 / DN125，不得拿外径直接当内径。例外：R1E 查不到可用 [σ]^t 时不走本退化、直接进 missing，条件与文案见 5.4.3 节。缺操作温度时两条路径仍都按本退化，只在“查不到 [σ]^t”这一条上分开。

R1E 专用许用应力（S30408 内置字典、S31603 查表 B.1）与腐蚀裕量优先级，统一见 5.4.3 节；本节只负责普通路径的表 B.1 查值。

## 5 壁厚

### 5.1 承压计算壁厚

> tc = P·Do / [ 2·(σ·E_j + P·Y) ]
>
> 直管内压；P 为 MPa、Do 为 mm、σ 即许用应力 [σ]^t（MPa，上标 t 表示设计温度下的取值；后文公式同此）；E_j = 1.0，Y = 0.4

按 GB/T 20801.1—2025 表 27（t < Do/6 时的 Y 值），Y = 0.4 的温度档是：铁素体钢 Td ≤ 482 ℃，奥氏体钢 Td ≤ 566 ℃；再往上铁素体钢 510 ℃ 档取 0.5、538 ℃ 起取 0.7，奥氏体钢 593 ℃ 档取 0.5、621 ℃ 起取 0.7，两列之间可按 6.6.1.1 的规定内插。本工具不按温度切换 Y，一律取 0.4：Y 位于分母且为加项，取小值只会得到更厚的壁厚，属保守简化；超出上述温度档的工况仍由 V7 提示复核，结果不能当作符合表 27 取值的结果。V7 在 Td > 450 ℃ 即保守告警，早于上述各档，超温工况一律先按 V7 复核。

公式形式上的适用条件是 t_c < Do/6，但普通路径只对 t_c(Pd) 做这一判断：若 t_c(Pd) ≥ Do/6，wall_mm 与 t_required_mm 留空，选档流程仍按 5.3 节工艺最小壁厚做几何退化选档并保留输出行（不进 missing），压力有效且等级号非空时 grade_code 仍正常生成；V3 因 t_required_mm 为空自动跳过。PN 档的 t_c(PN 档) 不单独做 t_c < Do/6 的**早退**判断，只作为 t_req = max(t_c(Pd), t_c(PN 档)) + C2 的厚度项（t_req 即不含负偏差的所需壁厚，负偏差在圆整与 V3 阶段另扣，见 5.2 节）。但若 t_c(Pd) 还在薄壁域内、PN 整档保护却把 t_c(PN 档) 顶到 ≥ Do/6，程序不会静默按薄壁公式出结论：备注里显式写「PN 整档保护压力 … MPa 下的承压厚度 t_c=… ≥ Do/6=…，薄壁公式不适用，结果需按厚壁公式或专项设计复核」，仍按两值中的较大者圆整，并保留输出行。R1E 路径按 5.4.1/5.4.2 节公式另行处理，其厚度不参与 PN 整档保护。该 max() 即「压力等级保护」；真空与 R1E 两条路径不参与。正常自动选档下 PN 档对应压力 ≥ Pd，因此 PN 项通常就是控制项，压力等级保护等效于按所在 PN 档压力计算承压壁厚；保留 max() 是给人工改档、旁路或边界异常留兜底。高温工况下仍用常温 PN 档压力与高温许用应力组合算壁厚，没有另做温度折减，结果偏保守。Pd 为空（缺压力或压力非法）时，本节壁厚路径直接返回空，不能按 0 MPa 继续算；Pd > 22.0 MPa 时没有可用的 PN 档，按 4.1 节保留输出行、按实际 Pd 算壁厚，但等级号与 PN 保护为空并提示专项设计。

E_j = 1.0 的前提：无缝管按整体成形取 1.0；焊接管暂按「100% 无损检测（RT/UT）」假设取 1.0，代码未按接头型式与检测比例折减。实际接头系数低于 1.0 时，应按 GB/T 20801 的规定折减后重算，不能直接沿用本表结果（见第 10 章）。

### 5.2 负偏差与圆整条件

默认负偏差等级 S2-B 为 −12.5%·S，故默认档 C1 = 0.125·S。但 C1 不是恒定的 12.5%，而由偏差等级与外径/壁厚比共同决定：负偏差等级解析按 grade 查 GB/T 17395 表 8 / 表 9（非标准化壁厚允许偏差），这两张表随本工具预置，不读外部数据文件，也不随三张标准表导入而更新（位置见附录 A）。表 8 按 S/D 所在区间选规则——对称偏差取 max(pct·S, abs_mm)，仅下偏差取 pct·S；表 9 直接取 |下偏差|·S；表 8 正常无空档；某档缺失时负偏差解析返回 0.0，按数据录入缺陷处理，不能当成「无要求」。默认档可由内部 options 改成表 8 / 表 9 中的其他等级：自动选档读 options.wall_tol_grade，人工 DN 重算读 options.wall_grade，两者都未传时按 S2-B；页面没有入口，管段记录里也不存这一字段。圆整不是简单「向上取一档」，而要同时满足两个不等式：

> S ≥ max(treq, 最小壁厚) 且 S − C1(S) ≥ treq
>
> S 取该外径标准壁厚序列中的最小值

### 5.4 高压不锈钢 R1E 公式

> **口径定标：R1E 是本项目专用、非标准的壁厚计算规则，不声称符合 GB/T 20801.1—2025、GB/T 150 或其他任何标准的符合性。** 它沿用项目指定的低应力字典、固定分母压力项（等效 Y=0.5）、12.5% 负偏差一次性除入与 PN100 不参与整档保护；这些都不是标准通式的完整实现。需要标准符合性结论时，必须按 GB/T 20801.1—2025 6.6.1.2 公式(1) 与表 27 另行计算，并保留 S、Φ、W、Y、C 的完整取值与适用条件；不得把本节结果当作标准符合性证据。

#### 5.4.1 触发路径与守卫（含 V13 判定）

进入 R1E 有两条路径，壁厚公式相同，且都不参与 PN 整档保护：① 压力带强制候选：材质 S30408/S31603，操作绝压落在 4.7 ≤ p ≤ 6.4 MPa（两端闭区间，按 kPa 比较；温度不作硬门槛），且设计压力 Pd ≤ 10.0 MPa，代号返回 R；若此时自然档已经是 R，则按下一条自然落档处理，不置强制标记、不报 V13。② 自然落档：设计压力 > 6.4 且 ≤ 10.0 MPa 时，压力代号规则本身给 R（10.0 MPa），S30408/S31603 同样按 R1E 公式。Pd > 10.0 MPa 是硬守卫：此时不强制升 R，也不走 R1E 公式，等级号回到自然 S/T/U 档（按 Pd 落在哪一档），壁厚回到 5.1 节通用公式并恢复对应 PN 整档保护；不会反向降级为 R 档，也不会出现「等级号 S/T/U、壁厚却仍按 R1E」的混合口径，且不报 V13。其他同样落入 R 等级号的不锈钢（如 S30403/S32168）仍走 5.1 节通用公式并叠加 PN100（10.0 MPa）保护；只有 S30408/S31603 进入 R1E 公式。这就是「只升不降」：升档判据与壁厚公式同开同关，不为套 R1E 公式而绕开压力等级。

缺操作温度时不进 R1E 公式，等级号仍是 R1E：R1E 壁厚公式要求设计温度非空，缺温度时触发路径与普通路径都按 4.2 节退化给几何 DN，壁厚、min_wall_mm、t_required_mm、stress_mpa 全部留空。等级号与温度无关：压力代号、顺序号、材质代号照常拼，S30408/S31603 在 4.7–6.4 MPa 带内输出仍是 R1E（无 -H/-C 后缀），不会退回 Q1E。升档判定与 V13 也只看「自然档是否已是 R」，同样不看温度：操作绝压约 4.7–5.67 MPa（Pd ≤ 6.4，自然档 Q）置真并报 V13；约 5.67–6.4 MPa（Pd > 6.4，自然档 R）为假、不报 V13。只有「有设计温度但查不到 [σ]^t」才分两条路径，详见 5.4.3 节。

R1E 路径同时采用 3.0 mm 作为小管最小壁厚下限参与圆整，覆盖表 5-1 中 DN ≤ 25 的 2.0 mm；该下限只抬高、不降低。

压力带为什么取 4.7–6.4 MPa：按默认 pressure_factor = 1.15、附加 0.15 MPa、下限 1.0 MPa，Pd = 6.4 MPa 对应操作绝压约 5.67 MPa，Pd = 10.0 MPa 对应约 8.80 MPa；Q1E 与 R1E 的自然分界也就在操作绝压约 5.67 MPa。压力带取到 6.4 MPa，只是把 4.7–约 5.67 MPa（自然档仍是 Q）这一段硬拉进 R1E，消除同族相邻流股跨在边界两侧时「一条 Q1E、一条 R1E」的壁厚跳变。操作绝压约 5.67–8.80 MPa 不需要再扩大强制带：这一段 Pd 已落在 6.4–10.0 MPa，按压力代号规则本来就自然落 R（路径 ②），公式、C 与「不吃 PN 整档保护」的口径与强制带完全相同，扩大压力带不改变任何结果，只会把「升档」的边界说糊。R1E 的真正上界由 Pd > 10.0 MPa 守卫给出：操作绝压约 8.80 MPa 以上（或高倍率使 Pd 提前越过 10.0 MPa）自然档进入 S（PN160，16.0 MPa），守卫同时关掉强制代号与 R1E 壁厚公式，壁厚回到通用公式并恢复 PN160 保护；若只为把 R1E 铺到更宽的压力范围而抬高这道守卫，就等于绕开 PN160 保护去削薄。固定上限还让 4.7 与 6.4 两个边界只在一处判定，避免同族流股反复跳档。

#### 5.4.2 承压公式与负偏差口径（含自定义 C1=0 语义差异）

> tc = Pd·Do / (2·σ·E_j + Pd) ； t = tc + C ； treq,nom = t / 0.875
>
> E_j 即 5.1 节的焊接接头系数，取 1.0；C 见 5.4.3；treq,nom 为含负偏差的所需壁厚，与 5.1/5.2 节不含负偏差的 treq 分开记。负偏差按 12.5%（即除以 0.875）预先折入 treq,nom，圆整与 V3 阶段置 C1 = 0，全流程仅计一次、不重复扣减；该 12.5% 由 R1E 专用常量固定，不受 5.2 节 grade（表 8 / 表 9）影响

公式形式：分母里的 +Pd 在代数上可写成标准通式取 Y = 0.5 的形状，但 R1E 仍是项目专用口径，不因此构成对 GB/T 20801 通式的标准实现或符合性声明。在完全相同的 P、Do、σ 下，其承压计算壁厚反而略低于 5.1 节 Y = 0.4；实际 R1E 圆整结果往往更厚，是因为 S30408 专用许用应力字典取值更保守，且未配置等级表、也未传 options 时默认回退 C = 1.0 mm，与公式形式本身的保守性无关。

两路径的 t_required_mm 不可直接横向对比：普通行（5.1/5.2/5.3）的 t_required_mm 不含负偏差，负偏差由圆整与 V3 统一扣 C1；R1E 行的 t_required_mm 已把 12.5% 负偏差除入（即上面的 t_req,nom），同时 C1 = 0。两路径的数值语义不同，不能把同一 t_required_mm 直接套到另一条路径比较。

自定义规格的 C1=0 在两路径下不对称：普通路径的 t_required_mm 不含负偏差，自定义规格按 C1 = 0 参与比较后，V3 实际比较的是人工输入的壁厚（未扣负偏差）与 t_required_mm，等于把人工输入壁厚直接当作可用净厚；使用者必须在 wall_override_mm 中自行预留制造负偏差，否则 V3 可能接受实际净厚不足的规格。R1E 路径下自定义规格同样 C1 = 0，但 12.5% 负偏差已预先除入 t_required_mm，所以仍按含负偏差的要求校核，二者不能互相套用。

该式在圆整前校核承压计算厚度 tc < Do/6，不含腐蚀裕量 C；t = tc + C 只用于后续所需壁厚与圆整。越界返回空、不硬算厚壁。C 不参与薄壁判据，避免小口径下 C 占比大时把可算组合误判成厚壁。

#### 5.4.3 许用应力与腐蚀裕量优先级

σ 用哪一套：S30408 用专用字典（100 ℃ 137、150 ℃ 123、200 ℃ 115、250 ℃ 109、300 ℃ 104、350 ℃ 100 MPa），100–350 ℃ 线性插值。该字典是本工具内置的保守工程取值，独立于用户导入的表 B.1：表 B.1 更新不会自动改写它，R1E 的 S30408 结果仍按这套字典；S31603 走表 B.1。边界行为：≤ 100 ℃ 钳位取 137 MPa；> 350 ℃ 直接返回空并早退，提示「设计温度超出 R1E 许用应力表范围（S30408 只到 350 ℃），需人工给 [σ]^t」，不做高温外推。S31603 走表 B.1：按表 B.1 的温度范围查值，设计温度超出该牌号最高温度时返回空并早退，提示「设计温度 X ℃ 超出表 B.1 中 S31603 的温度上限 Y ℃，查不到 [σ]^t，需人工给定」；整行未录该牌号时同样返回空并早退，提示「表 B.1 未录 S31603 牌号，查不到 [σ]^t，请补录该牌号或改用已录入材质」。两种情况都不生成输出行、无 DN，不走几何退化；把「缺牌号」与「超温」分开说，是为了让人知道该补表还是该降温，而不是先去改流速。

C 从哪来：先取管道等级表 corrosion_mm；等级表未定义时取内部 options.corrosion_mm（global）；两者都没有才回退工具内置的 R1E 默认腐蚀裕量 1.0 mm。直接以底层壁厚路由计算且未传入 R1E 腐蚀裕量时，底层也按 1.0 mm 回退；完整选档流程会先折算 R1E 实际 C。计算返回行同时给出 c2_mm（等级表 C2）与 r1e_c_mm（R1E 实际参与计算的 C），避免出现「C2 列写 3 mm、公式按 1 mm 算」的对不上账；这两个字段只在返回的行对象里，页面、Excel 与 AI 包均不单独落列（Excel「腐蚀裕量 mm」列取 c2_mm，见 9.1 节）。

#### 5.4.4 明细列核对与变薄风险

明细列不能混读：R1E 行的「计算壁厚」列对应 t_calc_mm，仍是通用承压壁厚公式（按 Pd、Do、σ 计算，见附录 A）的参考值；同列的 stress_mpa 也取表 B.1 普通查值。对 S30408，R1E 公式内部另取 5.4.3 的内置字典值，因此该行 stress_mpa 不等于实际 R1E 公式 σ；对 S31603，R1E 公式与 stress_mpa 同用表 B.1 值，两者一致。c2_mm 是等级表/全局给出的腐蚀裕量，r1e_c_mm 是 R1E 实际参与计算的 C，两者可能不同；两者都只在计算返回行里，页面、Excel 与 AI 包不单列。真正决定圆整与 V3 的是 t_required_mm = (t_c + C)/0.875。11.2 节 E5 的 2.37 mm 与 4.16 mm 正是这一区别：前者是通用公式参考，后者才是 R1E 所需壁厚。

自定义规格的净厚口径见 5.4.2 节；V3 始终按 wall_mm − c1_mm 与 t_required_mm 比较。

R1E 的变薄风险不只 S31603 与 C2=0：大口径默认 S30408 在 Pd 靠近 R 档下界（含操作绝压 4.7–6.4 MPa 的 R1E 区间）时，因跳过 PN100（10.0 MPa）整档保护，按 R1E 公式算得的壁厚也可能薄于带 PN100（10.0 MPa）保护的通用公式。若项目要求同等级全覆盖 PN100（10.0 MPa），须人工复核，不能只看等级号已到 R 就认为保护已足。

### 5.5 真空管道的外压筛查

> t_ext = Do · ( SF·P_ext / (2E/(1−ν²)) )^(1/3)
>
> 长圆筒弹性屈曲；P_ext = 0.1 MPa、SF = 3.0、E = 180000 MPa、ν = 0.3
>
> t_ext_req = t_ext + C2 ； treq = max( treq, t_ext_req ) ； S − C1 ≥ treq
>
> 外压筛查先并入 C2，再与真空内压计算项（tc(0.1 MPa) + C2）取大（不参与 PN 整档保护）；负偏差由统一圆整扣减

化简后 t_ext ≈ 0.00912·Do。外压厚度先算 t_ext_req = t_ext + C2，再并入 t_req，按 S − C1 ≥ t_req 统一圆整；报表里的 external_wall_mm 仍单独保存裸外压厚度，t_required_mm 才是含 C2 的最终要求。工艺最小壁厚与高温真空 10 mm 仍只作为 min_wall 名义下限；有可用壁厚档时，wall_floored 只在 min_wall 实际把档位抬高时才置真（判据见 5.3 节），min_wall > t_req 本身不构成标记理由；无可用壁厚档的退化判据见 5.6 节。由外压 t_ext_req 控制的壁厚只算稳定性要求，不得误打「工艺最小壁厚托底」。V3 直接比较 S − C1 与 t_required_mm，与这里的 t_req 同一口径；人工覆盖后的行同样按生效的 od/wall 与外压结果校核。高温真空（操作 ≥ 250 ℃）且 DN ≥ 400 时，名义下限直接提到 10 mm；DN ≥ 700 另提示需设加强圈。支撑跨距、椭圆度与温度折减仍需按 GB/T 20801.1-2025 6.6.1.3 与 GB/T 150.3 复核；只有同时满足 L/D ≥ 25、D/T_e ≥ 65、T ≤ 300 ℃ 时，长圆筒弹性屈曲式才与标准简化式同域，否则必须按 GB/T 150.3 的图表法另算。

E = 180000 MPa 是定值近似，未随材质与温度折减；该值低于 GB/T 20801.1-2025 表 C.2 中 20 ℃ 的弹性模量，在适用温域内偏保守，但超过 300 ℃ 不再覆盖。该取值只适用于碳钢与不锈钢（含本工具选型中出现最多的 20#、Q345、S30408、S31603）；钛材（F）、有色金属与非金属（G）管道的弹性模量与此相差很大（如钛约 100 GPa、PVC/PP 更低），用同一个 E 会系统性高估临界外压、把所需壁厚算薄。代码未按材质分流，因此这几类材质遇真空工况时，本表只作数量级参考，必须按实际材料弹性模量重算外压稳定性。它也只服务本工具的外压筛查，不能替代按实际材料高温弹性模量、支撑跨距与加强圈做的正式校核。

**完整校核不是这条筛查式。** GB/T 20801.1—2025 6.6.1.3 a) 要求按 D、L、T_e 与材料，依 GB/T 150.3 以 P ≤ [P] 确定计算厚度；6.6.1.3 b) 的简化式只允许 L/D ≥ 25、D/T_e ≥ 65、设计温度 ≤ 300 ℃，且材料限碳钢、低合金钢、奥氏体不锈钢或铸铁。当前代码的 0.1 MPa / SF = 3 / E = 180000 MPa 长圆筒式只是筛查：它不查 A/B 曲线、不输出许用外压 [p]，也不判定外压合格。落在上述门槛内时，它与公式(2)的系数近似等效；落在门槛外、材料不符或需要加强圈时，必须按 GB/T 150.3 的图表法另算，不能拿本工具的筛查厚度充当合格结论。

设计外压的取值也要分开：无真空泄放阀时取 0.1 MPa；装有真空泄放阀时取「1.25 倍最大内外压差」与「0.1 MPa」中的低值（GB/T 150.1—2024 5.3.3 d)）。当前代码固定取 0.1 MPa，是这两种规则的保守上包络，不能反过来把 0.1 MPa 当成有阀工况的唯一取值。厚度口径为 C = C1 + C2、δe = δn − C；Do/δe ≥ 20 时按 GB/T 150.3 图 6-2 / 表 6-2 查 A，再由材料 B 曲线查 B，[p] = B/(Do/δe)；Do/δe < 20 时按公式(6-4)取两项最小值。加强圈按组合截面实有惯性矩 Is ≥ I 判定，I 按公式(6-9)。计算长度 L 取相邻支撑线之间的距离；管架、法兰、管板只有截面惯性矩合格时才可当支撑线，不能默认管架就是支撑线。

完整方法、条款号与可填空输入表见 `docs/vacuum-external-pressure-check.md`。实际管线至少需要管道号、DN / Do、名义壁厚 δn、牌号与材料标准号、对应的 B 曲线图号、设计温度、设计外压 pc、实际支撑跨距 L、加强圈间距 Ls 与 As / Is、C1 / C2、圆度控制值。**这些参数未到位时，只能给出筛查厚度，不能给出外压合格结论，也不能把「按 0.1 MPa 筛查通过」写成「按 GB/T 150.3 校核合格」。**

### 5.6 圆整与焊接管兜底

圆整在标准壁厚序列中从小到大挑第一个同时满足 5.2 节两个不等式的值；序列缺失（表 1/表 4 未导入）时留空并注明缺标准壁厚序列，不拿经验值顶替。外径 Do > 630 mm 且表内无该规格时，按 HG/T 20553-2011 表 2.0.2-2 的 Ia 采购档兜底并标「需按采购规格复核」：DN700/800/900 为 6.3 / 7.1 / 8 / 8.8 / 10 / 11 / 12.5 / 14.2 / 16 / 17.5 / 20 mm；DN1000（Φ1016）无 6.3、7.1，为 8 / 8.8 / 10 / 11 / 12.5 / 14.2 / 16 / 17.5 / 20 mm。序列不含 18 mm 等非标档；不再用 6/8/10/12/14/16/18/20 的整数近似冒充采购壁厚。有序列但无可用档时，圆整函数返回的 wall_mm 留空。判无档有两个来源，必须分开说：(1) 名义下限本身就不够——min_wall 大于序列最大档 S_max，任何圆整都不可能满足；(2) 名义上够、扣负偏差后不够——最大档净厚 S_max − C1(S_max) < t_req。两者都不等于「所需壁厚大于名义最大壁厚」：逐档试算没有任何一档满足 S − C1(S) ≥ t_req 时同样判无档，此时名义所需 floor = max(t_required_mm, min_wall_mm) 可能小于 S_max。备注按三种情况写：① min_wall > S_max 时写「工艺最小壁厚下限 {min_wall:g} mm 超出该外径标准壁厚序列最大档 {S_max:g} mm，需改用更大外径、并联或专项设计」（若净厚同时不足，再追加「另：最大档扣负偏差后净厚 … 仍小于所需承压厚度 …」）；② 仅净厚不足时写「所需承压厚度 {t_req:.2f} mm 超过该外径最大标准壁厚 {S_max:g} mm 扣除负偏差后的净厚 {net:.2f} mm，需并联或专项设计」；③ 未给外径/等级、不做 C1 试算时写「所需承压厚度 {t_req:.2f} mm 超过该外径最大标准壁厚 {S_max:g} mm，需并联或专项设计」。文案里的「名义下限」始终指 min_wall 本身（不扣负偏差）；「净厚」只与 t_req 比，不能说成「min_wall 扣了负偏差」。圆整入口仍保留数值型 t_required_mm 与 min_wall_mm；wall_floored 只有在 min_wall 真把档位抬高时才为真，无档时按「min_wall > t_req」记录该标记但不代表已选出壁厚。选档步骤在 wall_mm 为空时只用「按 DN 取工艺最小壁厚」的兜底值反算可用内径，做几何退化选档，返回的仍是空 wall_mm；不把最小壁厚冒充实际壁厚。上层保留空壁厚并把该 note 加入 warnings，输出行不丢；V3 因 wall_mm 为空跳过，不产生 error finding。

匹配顺序为「先查已确认映射、再前置拦截、再按列表短路，正则内部从左到右」：先查表 B.1 的 104 个牌号确认表（见附录 A），命中即返回；表外牌号先过铬钼耐热钢前置规则（命中即返回「待确认」，不落 E 前缀）；再按牌号正则列表的列举顺序逐条匹配，第一条命中即返回，同一条正则内的分支同样按书写顺序取第一个可匹配的前缀；全部不中返回 unknown，由选型层暂记 E 并告警。前置规则存在的理由：1Cr5Mo、9Cr1Mo 这类表外牌号的数字结构与不锈钢短式 0?[0-9]Cr\d 重合，若不前置会被静默判成 E 且没有任何告警。

## 8 特殊工况

- 真空：判定、默认代号 L 与 is_vacuum 识别见 4.1 节；壁厚由最小壁厚与外压筛查控制，DN≥700 提示加强圈，深真空（≤10 kPa）另提示防闪蒸；操作 ≥250 ℃ 的真空管追加外压失稳专项复核提示（壁厚下限提到 10 mm 见 5.5 节），深真空且 ≥250 ℃ 再追加一条弹性模量折减提示。

- 低温：操作 ≤ −20 ℃ 时追加焊缝低温韧性与螺栓选型备注；保冷代号 -C 按设计温度 ≤0 ℃ 判定，而低温段设计温度取 t − 20 ℃，所以操作 −10 ℃ 就会落到 −30 ℃ 并加 -C。0 ℃ 附近（如 −0.1 ℃）因 t<0 直接取 t−20，会一步落到 −20 ℃ 以下，同时触发 -C 与 V7，需人工复核是否确为低温工况。低温不改变壁厚公式，也不触发材料降级。

- 高温：操作 ≥ 300 ℃ 时追加「需做热膨胀柔性应力分析（热膨胀补偿）」备注，只作提示，不改变选径、壁厚与等级号。

> **注：** 低温、高温各只输出一条提示，判据分别是操作温度 ≤ −20 ℃ 与 ≥ 300 ℃。低温一条同时覆盖「低温」与「深冷」两种说法（本项目未单设深冷阈值，统一措辞为「低温/深冷工况」）；高温一条为「高温管线」，不再并列旧版的「高温管线(≥300℃)」。

- 两相：8 m/s 基准、2000 Pa 动压头限速、上游液相内径下限；DN≥800 标分层风险。两相不按下界报流速不足。

- 汽蚀：近沸点液体压到 0.8 m/s；泵入口与升压线不参与该修正。

- 极低流量（微量流股）：0 < Q ≤ 0.01 m³/h 不参与自动选径，不给 DN 与壁厚，单列在「未选型 / 待人工确认」清单并回显流量，避免把仪表管、放空或备用线按工艺管选粗。

- 非标编号：不匹配四位数字保留原名并标 V10，不重映射。

### 9.2 生效行与导出边界

自动原值保留在 auto_dn / auto_od_mm / auto_wall_mm，生效行替换 dn / od_mm / wall_mm；页面、Excel、Word 报告与 AI 包读同一份生效行。管道页的「等级号」列在 grade_code 为空时显示「待确认」徽标，与 Word 报告编号里 -待确认 的占位同义，不是空白也不是 -None；该徽标只是页面提示，不影响选型结果本身。Excel/CSV 只有独立的「等级号」列、没有同名「管路编号」字段；grade_code 为空时该列保持为空，不写「待确认」，便于下游按空值筛选。校核状态与风险集中放「校核备注」列，管路编号保持纯净，可直接作 BOM 与 P&ID 的主键。

### 9.3 pipe_run 人工覆盖与壁厚重算

dn_override 人工 DN：按 DN→外径表取 OD，复用与自动选档相同的壁厚路由重算壁厚；材质表 1/表 4、PN 保护、R1E 与真空外压均按生效外径重新判定，R1E 仍受 Pd ≤ 10.0 MPa 守卫。重算后负偏差 C1 按生效壁厚重新求；R1E 行取 0。界面与写接口上，人工 DN 与自定义 od/wall 二选一；同时提交会被 400 拒绝。人工 DN 不受自动选档的跳过规则限制：前端下拉从 DN15 起即可直接选 DN65 / DN125，API 与库层面接受外径映射表中含 DN10 在内的全部档位；自动流程仍跳过 DN10 / DN65 / DN125。人工 DN 不在标准外径表时只加提示，保留自动规格，不猜壁厚。

自定义 od_override_mm + wall_override_mm：壁厚直接取人工值，c1_mm = 0，再用新外径重算 t_required_mm 供 V3 使用；界面/接口同样要求与 dn_override 二选一。仅当同一管段同时存在两套并行数据时（例如人工 DN 与自定义规格被同一条记录同时保存），公共合并层以自定义 od/wall 优先于 dn_override；管道页、导出表与校核使用同一份生效行。这里的 C1 = 0 只表示自定义规格不在圆整阶段另扣负偏差；R1E 已把 12.5% 负偏差折入 t_required_mm，而普通路径的 t_required_mm 不含负偏差，使用者必须在 wall_override_mm 中自行预留制造负偏差。两条路径的语义差异只在 5.4.2 节展开，此处不重复。

自定义规格的几何校验：保存层在 od/wall 成对校验之后，再要求 2×wall < od；2×wall ≥ od 返回 400，避免存进内径 ≤0 的记录。该校验只拦新写入，已有数据中的异常行仍可读取：运行期 overrides 仅在内径 >0 时写 effective_inner_mm 与 v_act_ms；泵侧取内径时对 od − 2·wall ≤ 0 返回空，最终判 unlinkable，原因写「没有可用的管内径」。

生效行同时进入 V2 流速反算与 V3 壁厚校核：V2 按生效内径反算实际流速，V3 按生效 wall_mm − c1_mm 与 t_required_mm 比较。缺设计压力或许用应力时 t_required_mm 为空，V3 自动跳过并保留缺项提示。泵侧共用同一份管段记录，字段与联动口径见《泵计算说明书》9.1、9.4 节。

### 11.1 E1 逐步复算

```text
输入：Q=18 m³/h，t=60 ℃，p=2.0 bar(绝)，x=0
1 相态 x=0 → 液体；介质代号 PL；v=1.5 m/s
2 内径 Di = 1000·√(4·(18/3600)/(π·1.5)) = 65.15 mm
3 设计压力 表压 = 0.2−0.1013 = 0.0987 MPa
Pd = max(0, 1.15×0.0987, 0.0987+0.15, 1.0) = 1.0 MPa
4 设计温度 Td = 60+20 = 80 ℃；Td≥65 → 保温后缀 -H
5 材质 默认 S30408；σ(80 ℃)=138 MPa；C2=0
6 承压壁厚 tc = 1.0×89 / (2×(138+1.0×0.4)) = 0.322 mm
7 等级保护 1.0 MPa → PN10（1.0 MPa）；t(PN) 同样 0.322
8 最小壁厚 DN80 → 3.0 mm；max(treq, 最小壁厚) = max(0.322, 3.0) = 3.0
9 圆整 S=3.0；C1=0.375；3.0−0.375=2.625 ≥ 0.322 → 取 3.0
10 等级号 L + 1 + E + (-H) = L1E-H
11 实际流速 v = (18/3600)/(π×0.083²/4) = 0.92 m/s
低于推荐下限 1.0 → 提示（DN65 被屏蔽，选到 DN80 后流速降到 0.92）
```

### 11.2 E5（R1E）关键项核对

E5 的 4.5 mm 由 R1E 公式决定：σ 取专用字典在 220 ℃ 插值得 112.6 MPa，t = Pd·Do/(2σ+Pd)+C = 5.6335×108/(2×112.6+5.6335)+1 = 3.64 mm，t/0.875 = 4.16 mm，圆整到该外径序列的 4.5 mm。此时「计算壁厚」列按通用公式展示的 2.37 mm 只是参考，决定圆整的是 4.16 mm 的所需壁厚。

E5 的 2.37 mm 是通用公式不含 PN 保护的承压厚度 tc(Pd)，不是 R1E 的最终所需壁厚。计算壁厚在页面（「计算厚度」）、Excel（「计算壁厚 mm」）与 AI 包（「计算壁厚_mm」）均有列，但不在第 9 章 Word 一览表十列内；C2 以 Excel「腐蚀裕量 mm」列落值，R1E 实际参与计算的腐蚀裕量不单独落列。详见 9.1 节。

E5 的 C 为什么是 1.0 mm：表 11-1 说明里的 C2 = 0 是按材质兜底的通用公式腐蚀裕量（不锈钢取 0）；R1E 的 C 另有优先级：管道等级表 > 内部 options.corrosion_mm（global）> 回退 1.0 mm。本示例前两项均未配置，故回退 1.0 mm。通用公式参考值 `t_calc_mm`（2.37 mm）为不含腐蚀裕量与 PN 保护的承压计算厚度 `tc(Pd)`；R1E 公式则将 `tc`（2.64 mm）叠加 `C = 1.0 mm` 得 3.64 mm，再除以 0.875 得所需壁厚 4.16 mm。两者不是同一口径；计算返回行同时给出 c2_mm 与 r1e_c_mm，避免出现「C2 列写 0、公式按 1 mm 算」的对不上账（Excel「腐蚀裕量 mm」列仍按 c2_mm 落值，见 9.1 节）。
