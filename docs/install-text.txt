========================================================
 aspen-insight 使用说明
 把 Aspen Plus 的仿真结果读成可查、可对比、可导出的本地数据
========================================================

先看你手里是哪一种:

  A. 有一个 aspen-insight.exe
     → 看第 1 节。双击就能用,不用装 Python。

  B. 是一个文件夹,里面有 start.cmd、app 文件夹,没有 exe
     → 看第 2 节。要先装 Python。

  C. 已经能打开网页,只想查某一步怎么做
     → 直接跳到第 4、5、6、7 节。

--------------------------------------------------------
 1. 用 exe(推荐给不写代码的同学)
--------------------------------------------------------

 1.1 放哪儿
     把整个文件夹放到路径里没有空格的地方,例如 D:\aspen-insight。
     不要放在 OneDrive / 网盘同步目录里,读库时容易冲突。

 1.2 启动
     双击 aspen-insight.exe。
     会弹出一个黑色窗口(那是程序本体,别关它),
     几秒后浏览器自动打开 http://127.0.0.1:8000  就是界面。

 1.3 第一次打开是空的
     页面会提示"还没有工况",这是正常的:仓库和包里都不带
     别人的工况库。工况库会在第一次启动时自动建在
     exe 旁边的 data 文件夹里。

 1.4 没有 Aspen,先看看界面长什么样
     先关掉黑色窗口,然后在这个文件夹里:
       按住 Shift 键 + 鼠标右键 → 「在此处打开 PowerShell 窗口」
       输入并回车:
           .\aspen-insight.exe --sample
     程序会把内置的示例工况装进去(121 条流股、含两个塔的报错),
     原来的库会先备份成 cases.db.bak,不会覆盖丢数据。
     之后页面就能看到流股、设备、流程图、对比页。

 1.5 接自己的模型
     ① 先在 Aspen Plus 里打开 .apw,并算完一次
        (Aspen 窗口标题形如 xxx.apw - Aspen Plus V15)
     ② 回到网页,点左上角蓝色按钮「读取当前工况」
     ③ 等进度条走完(一百多条流股大约 15–40 秒)
     ④ 读完就可以关掉 Aspen,数据已经存在本地库里,之后照样能看

     注意:
       - 本工具只读,不改你的模型,也不调用 Run / Reinit
       - 如果 Aspen 是"以管理员身份运行",本程序也要用管理员身份运行
       - 远程桌面 / 服务会话里看不到 Aspen 的 COM 对象,要在正常桌面用

 1.6 怎么停
     关掉那个黑色窗口;或者点网页左下角的「退出」。

 1.7 杀毒软件提示
     exe 没有代码签名,个别杀软会提示"未知程序"。
     选择允许 / 信任即可,程序只监听本机 127.0.0.1,不往外网发数据。

--------------------------------------------------------
 2. 用源码(有 Python 的同学)
--------------------------------------------------------

 2.1 装 Python
     到 https://www.python.org/downloads/windows/ 下载 64 位安装包,
     安装第一屏一定勾上「Add python.exe to PATH」。
     装完新开一个命令行窗口,执行 python --version,能显示版本才算成功。

     如果输入 python 弹出的是微软应用商店:
       到「设置 → 应用 → 高级应用设置 → 应用执行别名」,
       把 python.exe / python3.exe 关掉;或者改用 py -3。

 2.2 装依赖
     在这个文件夹里执行(只有两个包):
         python -m pip install -r requirements.txt

     国内网络慢就加清华镜像:
         python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

     验证(不报错即可):
         python -c "import win32com.client, openpyxl; print('依赖就绪')"

 2.3 启动
     双击 start.cmd(会开控制台,方便看日志),
     或者在文件夹里执行:
         python -m app.api

     常用参数:
         python -m app.api --port 8001     8000 被占用时换端口
         python -m app.api --no-browser    不自动开浏览器
         python -m app.api --sample        装内置示例工况,先看界面

 2.4 之后
     跟第 1.5 节一样:先在 Aspen 里打开模型算完,再点「读取当前工况」。

--------------------------------------------------------
 3. 更新与卸载
--------------------------------------------------------

     更新:下载新包解压到新目录,把旧目录里的 data 文件夹整个拷过来。
           旧库会自动补齐新版本增加的表结构。
           要保留的重点是 data\cases.db(所有读过的工况)。
     卸载:删掉文件夹即可。不写注册表、不装系统服务。
     清空:先关掉程序,删掉 data\cases.db(建议先复制一份备份),
           下次启动会重新建一个空库。

--------------------------------------------------------
 4. 管路选型(可选):要自己导入三张国标表格
--------------------------------------------------------

 「管道」页按流股算管径与壁厚,要用到:

     GB/T 17395-2024 的表 1、表 4(钢管尺寸与壁厚)
     GB/T 20801.1-2025 的表 B.1(材料许用应力)

 这些数值属于国家标准原文,受著作权保护,本项目不能附带,
 需要你自己从合法渠道取得标准后整理成 CSV。

 怎么导入:
     ① 打开网页「管道」页,点右上角「标准表」按钮
     ② 三个 CSV 各选一次(文件名不用改,按名字自动对上位置)
     ③ 点「导入并立即生效」,不用重启服务
     如果文件不合格,程序会一条条说哪里不对,而且整单不写,
     不会留下一半的数据。

 如果你的网页上没有「标准表」按钮(更早的版本):
     把三个 CSV 放进 data\preview\std\docx\ 目录(没有就新建),
     然后重启程序、刷新页面。

 不知道 CSV 该怎么整理:仓库 docs 目录里有
     pipe-standards-extract-prompt.md(给 AI 的录入提示词)
     pipe-standards-index.md(每张表在第几页)

 不导入也能用其它所有功能,只是「管道」页会一直显示"标准表未录入"。

--------------------------------------------------------
 5. 数据存在哪里
--------------------------------------------------------

     data\cases.db                         所有读过的工况(最重要)
     data\preview\std\docx\*.csv           管路选型的三张标准表
     data\config\piping-classes.json       管道等级表配置

 这些都在本机,不会上传到任何地方;换电脑把 data 整个拷走就行。
 导出的 Excel / AI 分析包在你点导出时自己选的位置。

--------------------------------------------------------
 6. 常见问题
--------------------------------------------------------

 问:双击 exe 黑窗口一闪就没了?
 答:多半是端口被占或被杀软拦。在这个文件夹里按住 Shift 右键 →
     「在此处打开 PowerShell 窗口」,手动执行 .\aspen-insight.exe,
     就能看到具体报错。也可以换端口:.\aspen-insight.exe --port 8001

 问:浏览器没自动打开?
 答:手动访问 http://127.0.0.1:8000 。

 问:点「读取当前工况」说找不到 Aspen 模型?
 答:按顺序查:① Aspen 是否已经打开并加载了 .apw;
     ② Aspen 是否是管理员权限运行 —— 若是,本程序也要同样权限;
     ③ 是否在远程桌面 / 服务会话里 —— 那里看不到 Aspen 的对象。

 问:python 不是内部或外部命令 / 弹出应用商店?
 答:装 Python 时没勾 PATH,重装时勾上;或用 py -3 代替 python。

 问:装了 pywin32 还是报 No module named 'win32com'?
 答:装依赖的 Python 和运行程序的 Python 不是同一个。
     用 python -m pip show pywin32 和 where python 对照路径。

 问:读取很慢,像卡住了?
 答:程序是逐个节点读的,一百多条流股 15–40 秒;
     页面上有进度和"卡在哪一步"的提示,别急着关。

 问:表格里很多「—」?
 答:那不是没有结果,是单位没被换算表覆盖(老模型常见),
     顶部「单位诊断」里有计数。

 问:管道页一直显示"标准表未录入"?
 答:正常,见第 4 节。不影响其它功能。

 问:关掉黑窗口后网页打不开了?
 答:服务跟窗口一起停了,重新启动即可。

 问:想换一台电脑继续看以前读过的工况?
 答:把 data 文件夹拷过去就行,不需要 Aspen。

--------------------------------------------------------
 7. 想核对下载是否完整
--------------------------------------------------------

 Release 页面说明里有一行 SHA-256。下载后在这个文件夹执行:

     certutil -hashfile aspen-insight.exe SHA256

 与页面上的值对比,一致就说明文件没坏、没被改过。
