## 1. 功能边界(先说清不做什么)

做:**按 Aspen 流股自动生成"管道一览表"** —— 自动填操作条件、自动选公称直径、自动查标准壁厚与等级号、自动加绝热代号,并做一致性校验,导出 Excel / AI 分析包。

不做(写进报告由人写,工具不代笔):

- 阀门、管件、法兰、支架的**数量统计**(需要 P&ID 与布置图,数据不在这里);
- 管道**应力分析**(柔性、支架推力),需要 CAESAR II 一类软件;
- 两相流**压降**公式(Lockhart-Martinelli 等),只做标记;
- 管长与压降(没有布置图,只能估算;等你要"水力学校核"时再单独立项)。

## 5. 计算流程(10 步,每步标依据)

```
输入:某条流股 —— 温度 t、压力 p、汽化率 vf、体积流量 Q、起点设备 → 终点设备
```

| 步 | 做什么 | 依据 / 口径 |
| --- | --- | --- |
| 1 | **判相态**:vf<1e-4 液;vf>1−1e-4 气;其余气液共存 | 注意痕量汽化率(库里有 1e-8),不能用 `==0` |
| 2 | **介质代号**:P + 相态 → PG / PL / PGL;AR、CA 按配置表(需你给含义) | HG/T 20519.6 风格 |
| 3 | **选流速** v:液 1.5(1.0–2.5)、气 15(10–25)、两相 8(5–10);**泵入口 0.8(0.5–1.0)** | 你定的口径 |
| 4 | **初算内径** D_i = √(4Q/(πv)) → 向上取 DN(T1) | 连续性方程 |
| 5 | **设计压力 P**:默认 1.1×操作压力;泵出口 ≥ 关闭压力;真空按 6.1.2.7;取与"管道级别"一致的 PN | 20801 6.1 |
| 6 | **设计温度 T**:<65 ℃ → 取介质温度;**≥65 ℃ 且无隔热层** → 取 0.95·t;**有保温层 → 直接取介质温度**(不折) | 20801 6.2.2.1(原文前提:无隔热层) |
| 7 | **许用应力 S**:牌号 + T 查表,缺温度用内插;T<40 ℃ 取 40 ℃ 值 | 表 B.1 + 使用说明 d) |
| 8 | **计算壁厚** t_c = P·D_o / [2(S·Φw + P·Y)],Φw=1(无缝)、Y=0.4;校验 t_c < D_o/6 | 20801 6.2.1 + 表 27 |
| 9 | **附加量** t_d = t_c + C1(负偏差,表 8/9)+ C2(腐蚀裕量) → **圆整到 T2 中该外径的标准壁厚**(取 ≥ t_d 的最小值) | 20801 6.4 + 17395 表 1/2/4 |
| 10 | **等级号与绝热代号**:PN ≥ 设计压力 → 压力代号;材质 → 材质代号;等级号 = 压力代号+顺序号+材质代号;t≥80 ℃ 加 `-H`,需要保冷 `-C`,防烫 `-P`,伴热 `-T` | HG/T 20519.6 |

**附加输出**:内径 D_i = D_o − 2×壁厚 → 反算**实际流速** v_r = 4Q/(πD_i²),必须落在第 3 步区间内,否则升一档重新算并记录"升档原因"。

### 5.1 体积流量从哪来(实测澄清)

本工具**不需要自己换算**体积流量:Aspen 直接给操作条件下的体积流量,`reader.py` 已按
`RES_VOLFLOW` 读取并统一换算为 m³/h(`units.py` 的 `volume_flow`)。现有 4 个工况 **100% 有值**(98/98、121/121)。

实测自洽性检查(2026-11-01):

| 流股 | 条件 | 质量流量 | 体积流量 | ρ=m/Q | 结论 |
| --- | --- | --- | --- | --- | --- |
| 0208 | 104.5 ℃ / 1.1 bar / 全液 | 17,361 kg/h | 19 m³/h | 931 kg/m³ | 与丙二醇/水混合液量级一致 ✅ |
| 0503 | 250 ℃ / 0.3 bar / 全气 | 26,401 kg/h | 71,800 m³/h | 0.368 kg/m³ | 反算 M≈53 g/mol,与丙烯醛/水蒸气吻合 ✅ |
| 0403 | 190 ℃ / 1.0 bar / 全气 | 31,487 kg/h | 132,379 m³/h | 0.238 kg/m³ | 反算 M≈9.2 g/mol,只有富氢气才成立 → 需与该流股实际组分核对 ⚠️ |

**两条注意事项**:

1. **两相流股**的 `VOLFLOW` 是 Aspen 给的混合总体积(按均相密度),不等于"气相体积 + 液相体积";
   两相选型本来就不套单相公式,所以只做标记,不据此判定成败。
2. 建议加一条**交叉校核**:把 `ρ=m/Q` 与 Aspen 侧密度(`RHOMX` / `RHO_LIQ` / `RHO_GAS`)比对,
   偏差 >5% 标黄 —— 既用现成数据,又能自证数据没读错(需多读 1 个字段/流股,见第 12 节)。


**管道级别(GC1/GC2/GC3)**:按 20801 4.1/4.2 判,涉及介质的毒性/易燃性类别(附录 A),工具对能识别的组分自动判,**判不了的标"待人工确认"**,不猜。

## 8. 样例计算(验证口径能否对上外部资料)

> ⚠️ 本节是**早期口径验证**,保留作记录;**最终口径以 §14 为准**(壁厚公式相同,但附加量、DN 取整规则已按 S1–S9 定稿)。

**样例 A|高压不锈钢段(样本模型 C风格)**:DN80,Φ89,设计压力 6.4 MPa,设计温度 190 ℃,16Mn,S=130 MPa(示例值,待表 B.1 核对)

```
t_c = 6.4×89 / [2×(130×1 + 6.4×0.4)] = 569.6 / 265.1 = 2.15 mm
t_d = 2.15 + C1(0.27) + C2(1.0) = 3.42 mm  → 取 Φ89 标准壁厚 4 mm
样本模型 C:5 mm(偏保守一档,原因见下)
```

**样例 B|常压不锈钢段(样本模型 B风格)**:DN80,Φ89,设计压力 0.34 MPa,30 ℃,S30408,S=137 MPa

```
t_c = 0.34×89 / (2×137) = 0.11 mm
t_d = 0.11 + 0.01 + 0 = 0.12 mm → 落到该外径最小标准壁厚 3.5 → 取 4 mm
样本模型 B:4 mm ✅ 一致
```

**为什么样本模型 C表普遍更厚**:DN500 在 3 bar 下样本模型 B写 14 mm、在 5 MPa 下样本模型 C写 25 mm。按 20801 公式,5 MPa、Φ530 算得约 12.8 mm,加附加量约 15 mm —— 样本模型 C那 25 mm 明显是按更高压力等级(或厂家等级表)取的。**所以第 9 节第 2 条必须你定:按公式算,还是按外部资料那种保守取法。**

## 14. 定稿口径(2026-11-01 收工版,S1–S9 已确认)

### 14.1 选型算法

```
1. 相态:vf<1e-4 → 液;vf>1−1e-4 → 气;其余 → 两相(不与手工覆盖,冲突标黄)
2. 目标流速(设计上限,不是必达值):
     液 1.5(1.0–2.5) | 气 18(10–25) | 两相 12(5–20)
     泵入口 0.8(0.5–1.0):仅当"该流股进入的设备类型 = Pump 且方向 in";识别不出 → 退回 1.5
3. D_calc = √(4Q/(π·v))  (Q 用 Aspen 的 RES_VOLFLOW,m³/s)
4. 取 DN:满足 OD ≥ D_calc 的**最小档**(OD 见 14.2)
5. 若最小档超过 DN600:退回 DN600,复核实际流速是否仍 ≤ 区间上限
     → 满足:采用并标"接近上限";不满足:标黄"建议分路并联或按风道专项设计"
6. 壁厚:t_c = P·D_o / [2(S·Φw + P·Y)],Φw=1(无缝),Y=0.4
       t_design = t_c × 系数(1.0 / 1.25) + C1 + C2,  C1 = 0
       C2:碳钢/低合金 1.0 mm,不锈钢 0(可按介质改)
       → 圆整到该外径的标准壁厚(取 ≥ t_design 的最小标准值)
7. 等级号:[压力代号][顺序号=1][材质代号],见 pipe-class-codes.md
8. 绝热代号:温度 ≥50 ℃ → `-H`;其余不加(C/P/T 人工勾选)
```
