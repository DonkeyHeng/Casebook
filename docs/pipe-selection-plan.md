## 1. 功能边界(先说清不做什么)

做:**按 Aspen 流股自动生成"管道一览表"** —— 自动填操作条件、自动选公称直径、自动查标准壁厚与等级号、自动加绝热代号,并做一致性校验,导出 Excel / AI 分析包。

不做(写进报告由人写,工具不代笔):

- 阀门、管件、法兰、支架的**数量统计**(需要 P&ID 与布置图,数据不在这里);
- 管道**应力分析**(柔性、支架推力),需要 CAESAR II 一类软件;
- 两相流**压降**公式(Lockhart-Martinelli 等),只做标记;
- 管长与压降(没有布置图,只能估算;等你要"水力学校核"时再单独立项)。

## 5. 计算流程(10 步,每步标依据)

```
输入:某条流股 —— 温度 t、压力 p、汽化率 vf、体积流量 Q、起点设备 → 终点设备
```

| 步 | 做什么 | 依据 / 口径 |
| --- | --- | --- |
| 1 | **判相态**:vf<1e-4 液;vf>1−1e-4 气;其余气液共存 | 注意痕量汽化率(库里有 1e-8),不能用 `==0` |
| 2 | **介质代号**:P + 相态 → PG / PL / PGL;AR、CA 按配置表(需你给含义) | HG/T 20519.6 风格 |
| 3 | **选流速** v:液 1.5(1.0–2.5)、气 15(10–25)、两相 8(5–10);**泵入口 0.8(0.5–1.0)** | 你定的口径 |
| 4 | **初算内径** D_i = √(4Q/(πv)) → 向上取 DN(T1) | 连续性方程 |
| 5 | **设计压力 P**:默认 1.1×操作压力;泵出口 ≥ 关闭压力;真空按 6.1.2.7;取与"管道级别"一致的 PN | 20801 6.1 |
| 6 | **设计温度 T**:<65 ℃ → 取介质温度;**≥65 ℃ 且无隔热层** → 取 0.95·t;**有保温层 → 直接取介质温度**(不折) | 20801 6.2.2.1(原文前提:无隔热层) |
| 7 | **许用应力 S**:牌号 + T 查表,缺温度用内插;T<40 ℃ 取 40 ℃ 值 | 表 B.1 + 使用说明 d) |
| 8 | **计算壁厚** t_c = P·D_o / [2(S·Φw + P·Y)],Φw=1(无缝)、Y=0.4;校验 t_c < D_o/6 | 20801 6.2.1 + 表 27 |
| 9 | **附加量** t_d = t_c + C1(负偏差,表 8/9)+ C2(腐蚀裕量) → **圆整到 T2 中该外径的标准壁厚**(取 ≥ t_d 的最小值) | 20801 6.4 + 17395 表 1/2/4 |
| 10 | **等级号与绝热代号**:PN ≥ 设计压力 → 压力代号;材质 → 材质代号;等级号 = 压力代号+顺序号+材质代号;t≥80 ℃ 加 `-H`,需要保冷 `-C`,防烫 `-P`,伴热 `-T` | HG/T 20519.6 |

**附加输出**:内径 D_i = D_o − 2×壁厚 → 反算**实际流速** v_r = 4Q/(πD_i²),必须落在第 3 步区间内,否则升一档重新算并记录"升档原因"。

### 5.1 体积流量从哪来(实测澄清)

本工具**不需要自己换算**体积流量:Aspen 直接给操作条件下的体积流量,`reader.py` 已按
`RES_VOLFLOW` 读取并统一换算为 m³/h(`units.py` 的 `volume_flow`)。现有 4 个工况 **100% 有值**(98/98、121/121)。

实测自洽性检查(2026-11-01):

| 流股 | 条件 | 质量流量 | 体积流量 | ρ=m/Q | 结论 |
| --- | --- | --- | --- | --- | --- |
| 0208 | 104.5 ℃ / 1.1 bar / 全液 | 17,361 kg/h | 19 m³/h | 931 kg/m³ | 与丙二醇/水混合液量级一致 ✅ |
| 0503 | 250 ℃ / 0.3 bar / 全气 | 26,401 kg/h | 71,800 m³/h | 0.368 kg/m³ | 反算 M≈53 g/mol,与丙烯醛/水蒸气吻合 ✅ |
| 0403 | 190 ℃ / 1.0 bar / 全气 | 31,487 kg/h | 132,379 m³/h | 0.238 kg/m³ | 反算 M≈9.2 g/mol,只有富氢气才成立 → 需与该流股实际组分核对 ⚠️ |

**两条注意事项**:

1. **两相流股**的 `VOLFLOW` 是 Aspen 给的混合总体积(按均相密度),不等于"气相体积 + 液相体积";
   两相选型本来就不套单相公式,所以只做标记,不据此判定成败。
2. 建议加一条**交叉校核**:把 `ρ=m/Q` 与 Aspen 侧密度(`RHOMX` / `RHO_LIQ` / `RHO_GAS`)比对,
   偏差 >5% 标黄 —— 既用现成数据,又能自证数据没读错(需多读 1 个字段/流股,见第 12 节)。


**管道级别(GC1/GC2/GC3)**:按 20801 4.1/4.2 判,涉及介质的毒性/易燃性类别(附录 A),工具对能识别的组分自动判,**判不了的标"待人工确认"**,不猜。

## 8. 样例计算(验证公式口径)

> ⚠️ 本节是**早期口径验证**,保留作记录;**最终口径以 §14 为准**(壁厚公式相同,但附加量、DN 取整规则已按 S1–S9 定稿)。

**样例 A|高压不锈钢段**:DN80,Φ89,设计压力 6.4 MPa,设计温度 190 ℃,16Mn,S=130 MPa(示例值,待表 B.1 核对)

```
t_c = 6.4×89 / [2×(130×1 + 6.4×0.4)] = 569.6 / 265.1 = 2.15 mm
t_d = 2.15 + C1(0.27) + C2(1.0) = 3.42 mm  → 取 Φ89 标准壁厚 4 mm
```

**样例 B|常压不锈钢段**:DN80,Φ89,设计压力 0.34 MPa,30 ℃,S30408,S=137 MPa

```
t_c = 0.34×89 / (2×137) = 0.11 mm
t_d = 0.11 + 0.01 + 0 = 0.12 mm → 落到该外径最小标准壁厚 3.5 → 取 4 mm
```

> 压力等级越高,壁厚越是由承压而不是由最小壁厚控制;低压段则相反。
> 这也是 §15.2 要另加一层最小壁厚下限的原因。

## 14. 定稿口径(2026-11-01 收工版,S1–S9 已确认)

### 14.1 选型算法

```
1. 相态:vf<1e-4 → 液;vf>1−1e-4 → 气;其余 → 两相(不与手工覆盖,冲突标黄)
2. 目标流速(设计上限,不是必达值):
     液 1.5(1.0–2.5) | 气 18(10–25) | 两相 12(5–20)
     泵入口 0.8(0.5–1.0):仅当"该流股进入的设备类型 = Pump 且方向 in";识别不出 → 退回 1.5
3. D_calc = √(4Q/(π·v))  (Q 用 Aspen 的 RES_VOLFLOW,m³/s)
4. 取 DN:按**实际内径**选档 —— 从小到大试,直到 `外径 − 2×选定壁厚 ≥ D_calc`(见 §15.1 的修正)
5. 若最小档超过 DN600:退回 DN600,复核实际流速是否仍 ≤ 区间上限
     → 满足:采用并标"接近上限";不满足:标黄"建议分路并联或按风道专项设计"
6. 壁厚:t_c = P·D_o / [2(S·Φw + P·Y)],Φw=1(无缝),Y=0.4
       t_design = t_c × 系数(1.0 / 1.25) + C1 + C2,  C1 = 0
       C2:碳钢/低合金 1.0 mm,不锈钢 0(可按介质改)
       → 圆整到该外径的标准壁厚(取 ≥ t_design 的最小标准值),**且不低于最小壁厚下限**(§15.2)
7. 等级号:[压力代号][顺序号=1][材质代号],见 pipe-class-codes.md
8. 绝热代号:温度 ≥50 ℃ → `-H`;其余不加(C/P/T 人工勾选)
```

#### 14.4.1 为什么不做「按组分自动判材质」(2026-11-07 决定)

原口径是"含氯/强腐蚀组分 → S31603",**已废止**。理由:

1. **腐蚀不是物质清单的函数**:同一物质在不同浓度、温度、含水量、氯离子 ppm、流速下结论可以相反
   (干氯气对碳钢几乎不腐蚀,痕量水就变剧腐蚀;稀硫酸可用碳钢,浓硫酸反而钝化)。
2. **组分清单里看不到决定性的那个**:304 在几十 ppm 氯离子下就可能应力腐蚀开裂,痕量组分才是关键。
3. **标准不提供这个结论**:GB/T 20801.1 附录 A 只做介质**毒性/易燃性**分类(用于 GC 分级);
   材料部分的牌号、许用应力、使用温度是机械性能边界。**该用哪种材料**在工程里由管道等级表定,
   常需材料/腐蚀专业判断或试验,不是拿 CAS 查表能得出的。
4. **名字不可靠**:Aspen 组分名是用户自起的 alias,实测同一模型里既有 `GLYCEROL` 也有 `CSHJZ`。
   真要做也应读 **CAS 号**(`\Data\Components\<id>\Input\CAS`),不是 alias。
5. **成本与产出不成比例**:逐流股读组分名 = +5–8 s/次读工况;而工艺流股只在 S30408 / S31603 之间选,
   两者**材质代号都是 E**,等级号一字不差,差别只在 `[σ]`(40 ℃ 时 138 vs 115 MPa)带来的厚度零头。

替代做法:工具只按**用户定义的管道等级表**套用材质与腐蚀裕量,并把**表里没定义过**的流股暴露出来;
组分数据只用于展示与检索(点开流股组成、导出里带组分名),**不对它下结论**。
示例配置见 [`samples/piping-classes.example.json`](../samples/piping-classes.example.json)。

### 15.2 最小壁厚下限(2026-11-07 加,用户拍板)

承压公式只管"承得住",不管"能不能施工"。1.0 MPa、DN15 不锈钢管按公式只需 0.07 mm,
圆整到标准壁厚是 0.5 mm —— 那是换热管/仪表管规格(GB/T 17395 表 4 里就有 0.5),工具真会选到它。
GB/T 20801.1-2025 4.1.6.2 要求「确定管道组成件最小厚度时,应包括腐蚀、冲蚀、螺纹深度或沟槽深度所需的裕量」,
所以小口径工艺管道实际由**最小壁厚**控制,必须另设一层托底。

| DN | 最小壁厚下限 | 说明 |
| --- | --- | --- |
| DN10–25 | 2.0 mm | 焊接/刚度 |
| DN32–65 | 3.0 mm | 同上 |
| DN80–100 | 3.0 mm | 同上(避免"DN65 比 DN80 还厚"的断崖) |
| DN125 起 | 不设限 | 承压所需已 ≥2 mm 量级 |

口径:`S = max(圆整值, 下限)`,下限**只抬高、不降低**;行里带 `min_wall_mm` / `wall_floored`,
Excel「管道计算书」有「最小壁厚 mm」「壁厚是否按下限」两列,页面勾「显示计算过程」能看到。
配置在 `pipe_data.MIN_WALL_BY_DN`,可被 `options["min_wall"]` 覆盖(传 `False` 关闭)。

实测影响(5 个历史工况,2026-11-07):壁厚变化 **41–85 条/工况**,管径升一档 **20–33 条/工况**
(#20 是 67/93 与 33/93);校验发现里 V6 不变,V2 净变化很小(#20 13→16、#21 19→21、
#22/#23 18→24、#19 20→18),**无新增错误、无新增"选不出"**。
原因是壁厚变厚 → 内径变小 → `select_dn` 按实际内径复核就得升档。

> 这条规则解决的是**能不能施工**,不是"贴近任何外部表格":改完管径比之前更大一点,这是预期内的。

**已知风险**:①`[σ]` 表逐格录入最耗时(约半天),出错会全表壁厚错;②两相流速按 8 m/s 偏保守,出报告时要写明这一口径;③标准表的数值不在仓库里,换机器/清 `data/` 后要重新录入(页面会退回 409 空态,不会静默出错)。

### 17.1 压力基准与真空等级(对应需求 1a)

- 绝压(bar)/表压(MPa)/绝压(kPa) 三个量在 `design_pressure()` 返回值里分字段给出:
  `表压 = 绝压 − 101.3 kPa`。库里 `pressure_bar` 是**绝压**,不要当表压用。
- 真空判定改为**只看操作绝压**:绝压 < 101.3 kPa 即真空。旧实现的"表压死区 −0.01 MPa"
  恰好把 0.913 bar(91.3 kPa)漏掉 —— 那是明确要抓的微负压流股(工况55 的 0103/0238)。
  **2026-11-18 第三轮收紧到 95.0 kPa(表压 < −6.3 kPa)**:1 bar = 100 kPa 的常压流股
  在 Aspen 里常有 1–6 kPa 建模压降,旧口径把它们判成真空、设计压力掉到 0.1 MPa;
  新口径只抓真正带负压的流股(详见 §19.1)。
- 真空管路等级代号用 **V1E**(V = vacuum),不再落 H1E:HG/T 20519.6 的 H 是 0.25 MPa
  压力代号,真空管挂 H 会与高压档混淆。V 是本项目扩展代号,`validate()` V4 对 V 不做
  PN 数值比较;V6 仍报"真空流股",新增 V11 提示 DN≥150 的外压复核。
- 增加**外压(真空失稳)最小壁厚筛查**:长圆筒弹性屈曲 `P_cr = 2E/(1−ν²)·(t/D_o)³`,
  取外压 0.1 MPa、SF=3、E=180 GPa、ν=0.3,反解 t_min 与内压所需壁厚取大。
  `E/SF/P` 在 `pipe_data`  configurable,经 options 覆盖。**这是筛查,不是正式外压计算**:
  真实支撑跨距、椭圆度、温度折减需按 GB/T 20801.3 外压章节专项复核 —— 报告里已写明。

  系列参加选型:计算内径落进这两档时自然上圆整到 DN80 / DN150。前端 `PIPE_DN_LADDER`
  同步去掉这两档。
- **防汽蚀限速**:液相 + 操作温度 80–105 ℃ + 绝压 95–130 kPa 视为近常压沸点吸入工况,
  流速上限压到 0.8 m/s(`near_boiling_liquid()`),只对非泵入口流股生效(泵入口本就 0.8)。
- **大口径两相流**:DN≥800 的两相流在 ρv²≤2000 Pa 之外加 V12「分层/波状流风险」;
  DN1000 焊接管最小壁厚由 6.5 提到 **10 mm**(保刚度),仍属工程下限不是标准值。

### 17.3 高压不锈钢升档(对应需求 1c)

- 操作绝压落 **4.8–5.6 MPa**、材质 S30408/S31603 的流股,压力代号强制升 **R(10.0 MPa)**,
  等级号 R1E(温度佐证但不作硬门槛 —— 用户确认 7 条全部升档,含 60 ℃ 的 PGL-0114)。
- 壁厚按**设计压力 + 16 mm 下限**控制,不按整档 PN10 的类保护:后者让 DN600 两相线要
  25+ mm,超出国标壁厚系列、选不出管;前者给 16 mm,既满足"≥16–18 mm"又采购得到。
  16 mm 下限只给 **DN≥100 主工艺线**;同带的仪表/排净小线(DN15/50)只升等级号,
  否则 16 mm 会超出其外径的可用壁厚。
- 效果:工况55 的 0107/0109/0111/0112/0113/0114/0122 由 Q1E(12–18 mm)升 R1E、壁厚
  统一 16 mm,不再出现"190 ℃ 高温管比 48 ℃ 低温管薄"的倒挂。

### 17.4 设计温度与保温(对应需求 3c)

### 17.5 异常流股与编号(对应需求 3a/3b)

## 18. 2026-11-18 第二轮校核修订(工程反馈)

第二轮复核(同日)对 §17 的四类问题做精准收紧,全部落在核心引擎,五个工况同步生效。

### 18.1 数据结构与格式解耦(最高优先级)

- 管路编号恢复**纯净**:`介质代号-流股号-DN-等级号`,不再拼接〔真空〕〔升R1E〕一类
  中文标记 —— 该列是 BOM 材料统计与 PID 匹配的唯一主键。
- Word 表新增第 10 列「**校核备注**」(最右),集中承载:真空/高温真空/加强圈、升 R1E、
  分层流风险、汽蚀限速、非标编号。列宽重排为
  (3.55, 1.05, 1.10, 1.30, 1.55, 1.35, 0.95, 1.50, 1.20, 2.45) cm,合计仍 16 cm。

### 18.2 R1E 壁厚公式化(取消 16 mm 硬编码)

第一轮的 16 mm 下限有三处副作用:DN350/400 偏厚、190 ℃(16 mm)比 173.4 ℃(20 mm)
薄的倒挂、DN600/4.9 MPa/205 ℃ 耐压不足。第二轮统一改为公式动态计算:

- **公式**:`t = P·D_o/(2[σ]^t·E_j + P) + C`,再除以负偏差系数 0.875,向上圆整到
  该外径标准壁厚序列(圆整时不再叠加负偏差,避免双扣)。P 按注 1,E_j=1.0,C=1.0 mm。
- **[σ]^t 字典**(S30408,用户指定):≤100 ℃→137、150→123、200→115、250→109、
  300→104、350→100 MPa,按设计温度线性插值;与录回的 GB/T 20801.1 表 B.1 并存,
  本字典只服务 R1E 族壁厚计算,偏保守。S31603 等其他牌号回退查表 B.1。
- **适用范围**:R1E 不锈钢族全体(4.7–5.6 MPa 升档 + 自然 R1E,如 0117/0120/0121),
  同族同公式 —— 同压力同外径时温度越高壁越厚,倒挂从机制上消除,不再吃整档 PN 类保护。
- **小口径保护**:R1E 小管最小壁厚 3 mm(DN15 的 PL-0123 由 2 mm 提到 3 mm,
  3 mm 下限使 0123/0108/0110 一并由 DN15/50 调整口径)。
- **压力带下限 4.8 → 4.7 MPa**:PG-0116/PL-0125(4700 kPa)并入 R1E,
  与 4800 kPa 不再在 Q1E/R1E 间跳档。实测升档流股由 11 条增至 13 条。

### 18.3 汽蚀限速与保温 -H 触发收紧

- 汽蚀限速(0.8 m/s)改为**三条件同时**:液相 + 80–105 ℃ + 绝压 **95–115 kPa**
  (原 95–130),且**排除泵排出口与升压管线** —— 流股压力比上游同流量同温度
  (流量差 ≤2%、温差 ≤2 ℃)流股高 0.05 MPa 以上,或拓扑上是泵出口,均不触发。
  工况55 实测:0136/0134(泵出口)与 0221(120 kPa)被正确移出,剩 0132/0206/0232/
  0242/0243/0245/0248;工况52 的 PL-0511(120 kPa)同样移出。
- 保温 -H 改按**操作温度 ≥ 45 ℃**(设计温度 ≥ 65 ℃,阈值常量 50 → 65):
  25–45 ℃ 常温管线不再误判包保温(工况55 的 0119、工况52 的 0119 一类)。
  48 ℃ 的 0117/0120 仍正确加 -H。

### 18.4 大口径真空专项与收敛联动(工况52)

  下降,常温 E 的外压筛查不够),备注「高温真空:外压失稳复核」。PG-0105(340 ℃)
  由 DN600/6 mm 调整为 DN700/10 mm(焊接管)并叠加加强圈提示。
- **DN ≥ 700 真空焊接管**:备注「需设外压加强圈,严禁全真空抽吸」(PGL-0519 DN900)。
- **未选型流股分类**:纯气相备注「可按低压风管(矩形/圆形薄壁风道)专项设计」,
  气液两相备注「需多管并联设计」(工况52 实测 6 条气相 + 5 条两相)。

## 19. 第三轮精细化规则(2026-11-18)

严格工程微调,全部落在核心引擎 + 快照读取入口,所有工况同步生效;
命令行审计见 `tools/make_pipe_schedule.py --audit`,表注由 `app/export/pipe_schedule.py::_notes()` 同源生成。

### 19.1 非物流剔除 + 真空阈值 95.0 kPa

- **读快照时按类型过滤**:`app/aspen/reader.py::stream_type()` 读 `\Data\Streams\<id>`
  节点属性 6(实测 `MATERIAL` / `HEAT` / `WORK`),随工况写入 `streams.stream_type`。
  选型侧 `pipe.is_material_stream()` 只放 MATERIAL 进主表 —— 热量流 `Q1`–`Q4` 与功流
  **既不进主表,也不进表末《未选型流股》清单**(它们不是"漏选的管线")。
  老库没有这个列时,退化为"名字形如 Q1/W2 且六项物料结果全空才剔除",
  避免把未 Run 的物料流股误删。`summary.excluded_nonmaterial` 记录剔除条数。
- **真空阈值 101.3 → 95.0 kPa**(表压 < −6.3 kPa):`100 kPa = 1 bar` 是工程建模里
  最常用的常压设定,带 1–6 kPa 压降时旧口径误判成真空;新口径把它留在常压档
  (`P_design ≥ 1.0 MPa`)。91.3 / 10 / 1.9 / 1 kPa 仍是真空。
  `ATM_MPA = 0.1013` 只用于表压换算,不参与阈值判定。

### 19.2 深真空(绝压 ≤ 10 kPa)专项备注

- `deep_vacuum`:备注追加「高真空(≤10kPa):严控吸入压降防闪蒸,建议全焊透/高真空法兰防漏气」。
- `deep_hot_vacuum`(≤10 kPa 且操作 ≥250 ℃):再追加
  「高温深真空:弹性模量折减,严格核算外压失稳支撑跨距」。
- 与 §18.4 的 `hot_vacuum`(真空且 ≥250 ℃、DN≥400 壁厚下限 10 mm)相互独立:
  一个管壁厚、一个管备注,可同时命中。
- 注 2 明确写「负压/真空液相吸入管线按防闪蒸限速(≤ 0.8 m/s)放大管径」,
  使深真空液相管(如 `PL-0330` DN350)与同流量常压线(`PL-0331` DN250)的管径差异可追溯。

### 19.3 DN1000 焊接管 +5% 容差

- `select_dn()` 新增 `oversize_band`:容差只在计算内径 `996–1045 mm` 生效
  (DN1000 的 Φ1016×10 → 标准内径 996 mm,+5% = 1045 mm)。
- 原先被踢入《未选型流股》的 `0222`(1008.4 mm)、`0215`(1035.3 mm) 一类流股
  现在选入主表 **DN1000 焊接管 × 10 mm**,备注同时给出内径与超径百分比:
  「流速略超上限(内径 XXX.Xmm),建议复核压降」+
  「计算内径略超DN1000上限(约 X.X%),需复核实际压降」。
- 容差可用 `oversize_tolerance=0` 关闭,区间可用 `dn1000_tol_min_mm` / `dn1000_tol_max_mm` 覆盖。

### 19.4 深冷 / 高温专项备注(按操作温度)

- 操作温度 ≤ −20 ℃:`低温工况:复核焊缝低温韧性及低温螺栓选型` +
  `深冷工况:复核焊缝低温韧性及低温螺栓选型`(两组措辞并存,便于不同口径复核)。
- 操作温度 ≥ 300 ℃:`高温管线:需做柔性应力分析(热膨胀补偿)` +
  `高温管线(≥300℃):需做热膨胀柔性应力分析`,不论压力高低。
- 这些提示进 `warnings`(网页「备注」列)与 Word 表「校核备注」列;
  封面统计(管路条数 / 其中焊接管 / 其中保冷管)直接由主表 `rows` 现算,
  与主表筛选结果同源,不另存计数(§19.5)。
