> 只看文字位置会误判成"第 1 列 ±15%、第 2 列 ±12.5%、第 4 列空"——**这就是第一版抄错的地方**。

#### 4.1.1 怎么客观核对合并格(别再靠肉眼)

按行列位置数竖线,而不是读文字:

```python
# 每个候选边界 x 处,统计该行带内被墨迹覆盖的高度比例
# 真边界 ≈ 1.00;合并没有线 ≈ 0.00–0.23
band = gray[int(y0*h)+4:int(y1*h)-4, :]
frac = max((band[:, int(f*w)+d] < 128).mean() for d in range(-3, 4))
```

表 8 实测(数据区 x = 0.225–0.893,四等分边界 0.392 / 0.558 / 0.725):

| 行 | 界1=0.392 | 界2=0.558 | 界3=0.725 | 数据格数 |
| --- | --- | --- | --- | --- |
| S1 / S2-A / S2-B / S3-A / S3-C / S4-A / S5 | 0.00 | 0.00–0.23 | 0.00 | 1(整行合并) |
| **S3-B** | **0.18** | **1.00** | **1.00** | **3** |
| S4-B | 1.00 | 1.00 | 1.00 | 4 |

> 这条核对方法是与 Agency 的 Reality Checker 专家交叉验证时定下来的:
> 第一版把 S3-B 读成 4 格、且第 4 格当成空,专家指出该行只有 3 格,按上面的墨迹检测**确认专家正确、已修正**。

### 4.3 本项目口径

- 无缝钢管常用 **S2-B / NS1(−12.5%)** 作为负偏差,本项目默认取 `−12.5% × S`,做成可配置项;
- 因为 C1 依赖最终选定的标准壁厚 S,壁厚圆整要解一个不等式:
  `S ≥ (t_c + C2) / (1 − 0.125)`,再向 T2 的标准壁厚序列上取整;
- 已编码进 `app/design/pipe_data.py`(`WALL_TOLERANCE_T8` / `WALL_TOLERANCE_T9` / `negative_deviation()`)。
