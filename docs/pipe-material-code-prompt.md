# 表 B.1 材质代号判定提示词(交给 AI 用)

> **做什么**:GB/T 20801.1 表 B.1 里的牌号要落进本项目的材质代号(A–H),等级号才会带对
> 材质段。代号是**项目约定**,不是标准原文;新导入或标准换版后,用这份提示词让 AI 逐行判定。
>
> **数据从哪来**:你已经整理好的 `data/preview/std/docx/t3-20801-tableB1.csv`(本地,不入库)。
> 这份提示词不含任何真实标准数据。
>
> **结果放哪**:确认后的代号写进 `app/design/pipe/data.py` 的 `MATERIAL_CODE_BY_GRADE`;
> 不确定的先留在待确认表,不要猜。

---

## 代号定义(项目约定,不要自行改)

| 代号 | 类别 | 典型对象 |
| --- | --- | --- |
| A | 铸铁 | HT/QT/KTH 等灰铸铁、球墨铸铁、可锻铸铁 |
| B | 碳钢 | 10、20、Q235、Q345、WCA/WCB/WCC、ZG 碳钢等 |
| C | 普通低合金钢 | 16Mn、Q345 系列低合金、10MnDG 等 |
| D | 合金钢 | 铬钼钢、低温镍钢(06Ni9DG、06Ni3MoDG、LC3、LC9)、其他合金钢 |
| E | 不锈钢 | 304/304L/316/316L/321/321H 等奥氏体不锈钢 |
| F | 有色金属 | 铜、铝、钛、镍基合金等非铁材料 |
| G | 非金属 | 塑料、玻璃钢等 |
| H | 衬里/内防腐 | 衬胶、衬塑、内涂等复合结构 |

## 判定顺序

1. 先看 `母材类别` 列(Fe-1 … Fe-11A / 铸铁),它是标准原文的分类,优先于牌号字面;
2. 铸铁 → A;不锈钢(Fe-8/Fe-9B 等) → E;低温镍钢、铬钼钢 → D;
3. 碳钢与普通低合金钢按含碳量/合金元素区分:Q235、10、20 → B;Q345、16Mn、10MnDG → C;
4. 一个牌号只能给一个代号;同一牌号在不同标准下重复出现时,代号必须一致;
5. 判不准的填 `待确认`,并在备注写清缺哪条依据,不要用“暂记 E”这种方式糊过去。

## 输出格式

严格输出 CSV,文件名 `material-codes.csv`,UTF-8 带 BOM,表头固定:

```
牌号,标准,母材类别,材质代号,判定依据,备注
```

- 一行 = 一个「标准 + 牌号」组合;同一牌号多标准各占一行,代号列必须相同;
- `判定依据` 写一句话(如“母材类别 Fe-8,奥氏体不锈钢”);
- `备注` 只写存疑点;没有就留空;
- 不要改牌号写法,不要合并行,不要输出标准原文的许用应力数值。

## 交付前自检

- [ ] 每个牌号都有代号,或明确标 `待确认`;
- [ ] 代号只在 A–H 内;
- [ ] 同一牌号跨标准的代号一致;
- [ ] 行数与输入的「标准 + 牌号」组合数一致,没有漏行;
- [ ] 末尾列一句:本次新增/变更了哪些牌号。

## 不需要 AI 做的事

- ❌ 不要重新解释标准条文,不要给选材建议;
- ❌ 不要把代号写进标准原文或对外传播;
- ❌ 不要为了“看起来完整”给不确定的牌号硬派代号。
