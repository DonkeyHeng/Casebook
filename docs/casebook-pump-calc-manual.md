## 1 适用范围与计算链

本说明书覆盖「设备 → 泵」页签背后的全部计算：进口基准 NPSHₐ（未计位差与管损）、装置有效 NPSHₐ（修正值）、设计扬程与选型扬程、吸入与排出两侧管路的沿程/局部阻力、建议电机档位，以及选型台账的三态判定。

页面、Excel 泵表与 AI 分析包泵表三条出口调用的都是同一组核心函数（逐条映射见附录 A 附表 A-1），所以口径只有一处；Word 报告不含泵参数表，泵在报告里只有能量衡算的一行轴功率（W 列）与汇总项「泵与压缩机总轴功」，不出 NPSHₐ、电机建议与告警（详见第 10 章）。本说明书按这条链路逐段展开。

**表 1-1 计算链总览**

| 环节 | 输入 | 输出 |
| --- | --- | --- |
| 泵块读数 | 流量、压升扬程 HEAD_CAL、效率、轴功率、密度 | 展示值 + Aspen 基准功率 |
| 进口基准 NPSHₐ | 进口压力、饱和蒸气压 p_v、密度 | NPSHₐ（未计位差与管损） |
| 两侧阻力 | 管段输入（L/Σζ/ΔZ/λ 口径）+ 管道页参数 | u/Re/λ/Σhf（两侧各一套） |
| 装置有效 NPSHₐ | 进口基准值 − 吸入段位压头 − 吸入段 Σhf | NPSHₐ 修正值 |
| 设计扬程 | 压升项 + 两侧 ΔZ + 两侧 Σhf | H 与 H_选型 = ceil(1.1H) |
| 照会轴功率 P_估 | 2.3 节密度；Q 按口径取泵块 VFLOW 或吸入流股流量；H 按口径取压升扬程或设计扬程；效率 | check_kw / design_kw（仅单相；design_kw 参与电机选档） |

| 选型台账 | NPSHᵣ + 余量 与 修正 NPSHₐ 比较 | 满足 / 不满足 / 无法判定 |

### 2.1 泵块读数

**表 2-1 泵块读数与用途**

| 字段 | Aspen 节点路径 | 单位与换算 | 缺值行为 |
| --- | --- | --- | --- |
| 流量 Q | \Data\Blocks\<泵块名>\Output\VFLOW | m³/h；l/min×0.06、l/s×3.6、gal/min（美制 US gal）×0.2271247、ft³/h×0.02831685 | 不影响两侧管段流速与阻力（两侧各自取流股体积流量）；仅影响泵表展示与第 7 章照会轴功率 P_估（仅单相；含气/两相进口为空；design_kw 固定取吸入流股流量，不受 VFLOW 缺失影响）；缺失时 check_kw 为空 |

| 摩尔密度 RHO_LIQ | \Data\Blocks\<泵块名>\Output\RHO_LIQ | kmol/m³；节点单位串原样时按 molar_density 表换算（kmol/cum 1.0、kmol/l 1000、mol/l 1.0、mol/m³ 0.001、mol/cc / mol/ml / gmmol/cc 1000、lbmol/ft³ 16.018463） | 缺失、非数值或单位串不认识时留空；它只是泵块密度回退项的因子，单相优先用进口流股 m/V，见 2.3 节 |
| 分子量 MW_LIQ | \Data\Blocks\<泵块名>\Output\MW_LIQ | kg/kmol；按 number 原样读取，不做换算 | 缺失或非数值时留空；与 RHO_LIQ 任一为空，泵块质量密度 RHO_LIQ × MW_LIQ 即为空，不回退猜测 |

> **注：** 读取快照的单位换算边界：泵块与流股读取都按每个 Aspen 节点自带的 UnitString 逐字段换算，目标单位固定为 ℃、bar、kg/h、kmol/h、m³/h、m、kmol/m³、kW 与 cP（℃ 由管路侧共用同一换算表）。这套目标单位是公共读取层的口径，泵计算直接用到的是 bar（进口压力与汽化压力）、m（压升扬程）、kg/h 与 m³/h（计算流股质量密度 m/V 及体积流量）、kmol/m³（泵块摩尔密度）、kW（轴功率）与 cP（粘度）；其中的 ℃、kmol/h 属读取层统一换算的目标单位，泵计算本身不使用（温度只做读取与告警显示，摩尔流量不进泵公式）。ENG 单位集下的 lb/hr、ft³/hr、gal/min、ft-lbf/lbm 等都在换算表中，按显式系数换算，不按单位集名整体缩放，也不假设模型一定是 METCBAR。MW_LIQ 走 number 原样（kg/kmol）；值为空、单位串缺失或不认识时一律留空，不猜默认单位。pressure 表只收绝压单位串（bar、atm、Pa、kPa、MPa、psi/psia、mmHg/torr、kgf/cm²，系数依次为 1、1.01325、1e−5、1e−2、10、0.0689475729、0.001333224、0.980665）；psig、barg、kPag、MPag 这类表压单位串不在表内，单位串查不到时返回空、该字段留空，不按「表压 + 1 atm」自行折成绝压，也不按单位集名整体缩放。表 2-1 的压升 Δp 与表 2-2 的 p_in / p_out / p_v 都走这条边界；Δp 在物理上是压差，代码仍按同一张 pressure 表换算（表内均为线性系数、无偏移），因此 psid、bard 这类差压单位串同样查不到 key、字段留空。HEAD_CAL 走 length 表，除 m / meter / m-kgf/kg 外，ft 与 ft-lbf/lbm 均按 1 ft = 0.3048 m 显式折算，j/kg 按除以 9.80665 折成米液柱。

> **注：** HEAD_CAL 只是压升项 Δp/(ρg)，不含位压头与管路阻力，界面称「压升扬程」而不是「扬程」；IN_PRES 的全称是 Increase in Pressure（压升），实测也是压升而不是进口压力，代码不拿它算 NPSH，只在页面设备表里展示。若泵块密度与流股 m/V 偏差较大，不要只凭 HEAD_CAL 与 Aspen 压差下结论；按 2.3 节用同一密度交叉核对 HEAD_CAL ≈ (p_out − p_in)×10⁵/(ρg)。

流股字段与泵块字段共用 2.1 节的读取层换算边界：按 Aspen 节点 UnitString 换算到固定目标单位，ENG 单位串按显式系数处理；温度、压力、质量流量、体积流量任一为空或单位不认识都留空，不用默认单位补算。

p_v 的候选路径是 \Data\Streams\<流股>\Output\STRM_UPP\PBUB\MIXED\TOTAL（V11 实测为 MIXED\LIQUID），读取时在每一层级按 TOTAL → MIXED → LIQUID 的优先级匹配子节点，并逐层下钻，直至到达无子节点的叶子（节点名大小写不敏感，不假设固定层数）。目录节点与叶子的判定是「有没有子节点」，不是「值是不是 1」：有子节点即目录，按相名继续下钻；无子节点即叶子，直接取值并做单位换算。因此真实 p_v = 1 bar 的叶子会被正常保留，不会因为数值等于 1 被过滤；PBUB / PL 这类目录虽然也读作 1 bar，但因为有子节点，仍按目录处理。PL 的分压在组分叶子，遇到组分名（不是相名）无法下钻时返回空，不会把目录标志 1 当成 p_v。μ 的 MUMX/VISC 下钻共用同一规则。

MUMX 分支优先 \Output\STRM_UPP\MUMX\MIXED\TOTAL（混合总粘度）；若模型没有 TOTAL、只有 MIXED\LIQUID，实际取纯液相粘度。两相流股也走同一路径，不是无条件取混合粘度；需要改用其他口径时，可在管段记录里手填 μ 覆盖。旧版模型把 VISC 直接挂在 \Output\STRM_UPP\ 下，STRM_UPP\VISC\… 系列候选仍保留，匹配顺序排在 MUMX 之后。

### 2.3 密度：两条路径

```text
若 进口流股存在 且 (进口汽化率 为空 或 ≤ 1e-4)：
ρ = 进口流股 质量流量 / 体积流量 （单相，实测密度）
否则：
ρ = RHO_LIQ(kmol/m³) × MW_LIQ(kg/kmol) （泵块值，质量密度）
```

两条路径的来源不同：同一台泵的泵块密度与流股 m/V 可能显著不同（实测样本差 24%），同模型其余泵一致到 0.02%，因此单相优先用流股实测。该密度用于装置 NPSHₐ，也用于第 7 章照会轴功率 P_估；进口流股 vol_flow 缺失时，只要泵块 RHO_LIQ × MW_LIQ 回退可用，check_kw 仍有值；design_kw 的 Q 与两侧阻力同取吸入段流股体积流量，不会改用泵块 VFLOW 替代，流量为空即 design_kw 为空。两侧管段各自用自己的流股密度（m/V），可以互不相同。

单相密度回退规则：进口流股存在且 vap_frac 为空或 ≤1e-4 时，只有 mass_flow 与 vol_flow 均非空、有限且严格 >0 才走 m/V；任一缺失、非有限或 ≤0 时自动回退到泵块密度 RHO_LIQ × MW_LIQ；仅当泵块密度也缺失时返回空。负流量不参与相除，避免算出负密度。该回退只用于 NPSHₐ 与 P_估；两侧管段水力计算不使用泵块密度，见下一段。

两侧管段各自取本侧密度：吸入与排出分别用本侧流股的 mass/vol，不采用泵块密度回退；mass 或 vol 缺失、非有限或 ≤0 时直接保持为空。自动 λ 口径下该侧进入缺项「密度」；手填 λ 口径下密度不阻断 Σhf，只让 Re 留空。

密度偏差的交叉核对：若泵块密度与流股 m/V 偏差较大，先按 HEAD_CAL ≈ (p_out − p_in)×10⁵/(ρ·g) 用同一 ρ 复算，确认不一致来自密度口径还是压升读数；不要直接用两套密度互相证明。

| note | 备注 | — | 不限长度 | 仅回显与说明用，不参与任何计算；保存层去首尾空白，空串落 null |

两侧 ΔZ 必须共用一个泵基准面：吸入段 ΔZ 的终点与排出段 ΔZ 的起点都取同一泵基准（工程惯例为泵轴中心线标高），而不是各取各的设备接管标高。只有共用一个基准，第 5 章 H 式里的 ΔZ_吸入 + ΔZ_排出 才等于「下游有效终点标高 − 上游所取液面」的总位差；两侧各按自己的接管标高取值时，两段位差会在泵体处重复或漏算，H 与选型扬程随之后偏，且从界面上看不出原因。记录里的 ΔZ 仍是沿流向的「终点 − 起点」，代码不做基准面校验（也没有模型几何可校验），需在填表时自行统一；改基准面属于改输入，不是改算法。取值时，上游起点通常取最低操作液面（塔釜或槽罐的低液位报警值），下游终点按进料方式取顶部进料接管标高（顶部非淹没进料）或最高操作液面（侧向 / 底部淹没进料）；同一对上下游流股两段合计的位差，应等于「下游有效终点标高 − 上游所取液面」。

## 3 进口基准 NPSHₐ（未计位差与管损）

> **注：** 压力边界的假定：本册把 Aspen 泵进口流股压力当作「上游容器操作压力」，泵出口流股压力当作「下游容器操作压力」，两者都不含管路位差与阻力。若 Aspen 模型已在上游/下游计入管损（例如上游设备至泵进口之间，或泵出口至下游设备之间已建有管路/阀门压降模块），就不能再在第 2.4 节的管段记录里重复填 ΔZ 与 Σhf，否则扬程与 NPSHₐ 会被扣两遍。判别办法：确认模型里泵进出口流股的压力是否已按「设备管口法兰」取值，或设计资料是否已扣除泵出入口管道阻力。

> NPSHₐ(进口基准) = (p_进口 − p_v) × 10⁵ / (ρ · g) ， g = 9.80665 m/s²
>
> p 取 bar 绝压，ρ 取 kg/m³，结果 m；尚未扣吸入段位差与管损

速度头项的处理：泵入口 NPSHₐ 按法兰静压定义为 NPSHₐ = p_s/(ρg) + u_s²/(2g) − p_v/(ρg)。由上游液面（速度 u₁ ≈ 0）到泵入口列伯努利方程，有 p_s/(ρg) = p₁/(ρg) − ΔZ_吸入 − Σhf_吸入 − u_s²/(2g)；两式相加，u_s²/(2g) 恰好抵消，得到 NPSHₐ = p₁/(ρg) − ΔZ_吸入 − Σhf_吸入 − p_v/(ρg)。因此以液面压力展开时，吸入管动压头已并入 NPSHₐ 定义项本身并在推导中抵消，公式里不再单列速度头项：进口基准式只算 (p_进口 − p_v)/(ρg)，装置有效式再扣吸入段 ΔZ 与 Σhf。若上游边界是来料管段，被忽略的是该边界速度头，按泵入口推荐流速 0.8 m/s 计仅约 0.03 m。非法值拦截：p_in ≤ 0、p_v ≤ 0、ρ ≤ 0，或任一为非有限值（NaN/Inf），均拦截判空，返回空而不是 0；p_in < p_v 时给出负值，表示会汽蚀，不吞成 0。|NPSHₐ|<0.005 m 时归零，避免表里出现 −0.00。

工具不使用 Aspen 自带的 NPSH-AVAIL 字段：实测一份模型逐值吻合、另一份量级到 6–1030 m，因此统一以自算值为准。

## 4 装置有效 NPSHₐ（修正值）

> NPSHₐ(装置有效) = NPSHₐ(进口基准) − ΔZ_吸入 − Σhf_吸入
>
> 只扣吸入侧；ΔZ 为沿流向标高差（终点 − 起点），泵在吸入起点之下时为负，修正值增大

修正项只有吸入段自己的两项都非空才算；任一缺失，修正值判空并写明缺「吸入段阻力 / 位压头」，三态随之判「无法判定」。进口基准值始终与修正值并列显示，但选型判据只用修正值（装置有效值）。

汽化率缺失的风险提示：汽化率缺失时不阻断计算，NPSHₐ 与设计轴功率仍按液相暂估；但整泵计算的 warnings、选型台账三态理由、页面提示，以及 Excel 整本/分类与 AI 包泵表的「提示」列都会写「缺汽化率，暂按液相估算，请复核」。这条提示不进 Word 报告：Word 报告没有泵参数表，也不逐台列 warnings，只在 Excel「泵」表、页面表与台账里出现；引用 Word 报告时不能以为报告中已提示该估算状态。这是估算状态，不是已确认单相。若上游实际是漏读汽化率的两相流股，液相 NPSHₐ 与设计轴功率会偏乐观，可能误判为「满足」；必须结合管路页的汽化率/两相告警与抽检复核，不能只看泵页结论。

含气/两相进口（汽化率 >1e-4）不计算 NPSHₐ，与《管路选型计算说明书》3.1 节同一阈值 1×10⁻⁴。这类进口已含气相，单相汽蚀余量公式的前提（净正吸入压头全部由液相提供）不成立，不是换一个密度值就能修正。页面、Excel 泵表与 AI 包泵表同为空值；Word 报告本身不含 NPSHₐ 字段，引用各导出结果时都不会拿到失效数值。

轴功率照会同样受这一门禁：汽化率 >1e-4 时，压升扬程口径与设计扬程口径的 shaft_kw_estimate.check_kw、design_kw 都返回空；完整原因与边界见第 7 章。

## 5 设计扬程与选型扬程

> H = Hpr + (ΔZ_吸入 + ΔZ_排出) + (Σhf_吸入 + Σhf_排出)
>
> Hpr 为 HEAD_CAL（压升扬程），可为负；ΔZ 与 Σhf 来自两侧管段

HEAD_CAL 是按泵块密度反算的压升项；若泵块密度与流股 m/V 偏差较大，应按 2.3 节用同一密度交叉核对，不能只凭 HEAD_CAL 与 Aspen 压差下结论。

速度头假设：本式默认上下游液面速度头差约等于 0，因此只叠加压升项、位差与阻力，不含 (u_out² − u_in²)/(2g)。若两端不是大液面而是管道接口，或两端流速差异显著，需按实际管口流速另加速度头项复核；HEAD_CAL 本身只是压升，不含速度头。

调节阀与设备压降不在本工具的输入项内：H 只由压升项、两侧 ΔZ 与两侧 Σhf 组成，没有调节阀压降 Δp_cv 字段，也不扣塔、换热器、流量计等设备的进出口压降。这类损失若必须计入，只有两条路：在 Aspen 出口压力中预留（使 HEAD_CAL 或 p_out 已含该部分压降），或在本工具结果之外另行叠加复核。本表的 H 不是含调节阀的全系统扬程，不能直接当作选泵扬程使用。

> H_选型 = ceil(1.1 × H)
>
> 先乘 1.1，再向上取整到 1 m

实现按十进制高精度（Decimal）计算后再向上取整，避免二进制浮点误差导致 H = 50 / 90 / 100 m 等边界值多进 1 m。

缺任一侧、该侧某个 ΔZ / Σhf 为空，或 HEAD_CAL 缺失时，H 与 H_选型都不给，只用「已计位压头」「已计阻力」给出中间量，并注明两侧未齐或压升扬程缺失。页面顶部余量倍率（1 / 1.05 / 1.10 / 1.15 / 自定义）仅作用于页面前端展示层的流量、压升扬程与「复制选型参数」行；它不改写三条出口共享的底层计算结果，也不进入 Excel / AI 包 / Word 报告或数据库，不作为 API 参数；不乘轴功率、建议电机、NPSHₐ、效率、p_v、粘度，更不作用于设计扬程 H 与选型扬程 H_选型——后者已内置 1.1 裕量。

H ≤ 0 属反向/自流工况：只给设计扬程并标「反向/自流」，不给选型扬程，不拿负数取整冒充结论。

两相管段仍按单相公式计入 H：两相吸入/排出管段的 Σhf 按单相达西公式（混合密度 + MUMX 下钻粘度或管段手填值，见 2.2 / 6.3 节）计算并计入设计扬程 H，无两相拦截或告警；模型边界与压降低估风险见 6.3 节与表 11-1。

## 6 沿程与局部阻力

### 6.1 内径与达西公式

> d = Do − 2·S [mm] ； d_m = d / 1000 [m] ； u = (Q/3600) / (π·d_m²/4)
>
> 全章统一：Do、S、d 用 mm；d_m 为 m，只用于流速、Re 与 Σhf；u 单位 m/s
>
> Σhf = ( λ·L/d_m + Σζ ) · u² / (2g) ， g = 9.80665 m/s²
>
> λ 为达西摩擦因数；L 取 m、d_m 取 m，Σhf 为 m

保护规则：L 与 Σζ 任一为空，该侧 Σhf 都直接给空、状态判「未填」——只填 L 不填 Σζ 不会得到「仅沿程」的数，因为少算的正是全部局部阻力。d ≤ 0、L < 0、u < 0 同样返回空；缺项列表分别写「管长 L」「管件系数 Σζ」。显式填 0（确实没有管件）与留空是两种语义：库里前者存 0、后者存 NULL。

内径 d ≤ 0、管长 L < 0、流速 u < 0 时该侧 Σhf 返回空。u = 0 时 Σhf = 0；但 Q ≤ 0 时流速计算先返回空，界面与导出的 Σhf 仍为空，不会出现「有管长、有 Σζ 却显示 0 m」的假结论。

零值边界：L = 0 为合法输入，Σhf 只余局部阻力项 Σζ·u²/(2g)；若 Σζ 也为 0，则 Σhf = 0.0。体积流量 Q = 0 时流速计算直接返回空（不是 0），Re 与 Σhf 均为空；自动 λ 与手填 λ 两种口径都判未填，缺项包含「体积流量」。

管道页只给几何 DN、wall_mm 为空时：泵侧仍保留该侧 dn 与 od_mm，但 wall_mm 留空，由 d = Do − 2S 得不到内径，id_mm 为空；该侧状态判 unlinkable（界面「无法关联」），原因固定写「没有可用的管内径」，并在进入缺项列表前提前返回。缺压力、缺温度、缺许用应力或厚壁越界这几种根因不会在这里逐条透传，需回管道页看该行的缺项与备注；对应退化口径见《管路选型计算说明书》3.6 节与表 7-2。

### 6.2 雷诺数

> Re = d_m·u·ρ / (μ/1000)
>
> d_m 为 m（与 6.1 同一符号）；μ 由 cP 换成 Pa·s；任一项为空或 ≤0 则返回空

两侧 ρ 各自取本侧流股的 mass/vol，互不共用；mass 或 vol 缺失/非正时直接保持为空，不回退泵块密度。自动 λ 口径把「密度」列入缺项，手填 λ 口径不阻断 Σhf。完整规则见 2.3 节。

### 6.3 摩擦因数 λ 的三种口径

自动口径按 Re 分三段：Re < 2300 取层流式，2300 ≤ Re < 3000 属过渡区（回退 Colebrook，工程近似），Re ≥ 3000 用所选湍流口径。手填 λ 不走这一分支。

**表 6-1 三种 λ 口径**

| 口径 | 公式 | 适用条件与实现 |
| --- | --- | --- |
| 自动口径（层流分支） | λ = 64/Re | Re < 2300 时优先取层流式，不调用 Colebrook/顾毓珍；仅对自动口径生效，不覆盖手填值 |
| Colebrook（默认） | 1/√λ = −2·log₁₀( ε/(3.7d) + 2.51/(Re·√λ) ) | 隐式迭代：初值 λ₀ = 0.02，最多 60 次；收敛判据为相邻两次迭代解的绝对差 \|λ_next − λ\| < 1e-10；60 次仍未达标时返回最后一次有限解（不报错）。λ 非有限或 ≤0 时返回空。相对粗糙度 ε/(3.7d) 无量纲：ε 与 d 同取 mm |
| 顾毓珍 | λ = 0.01227 + 0.7543 / Re^0.38 | 清洁/一般工业钢管湍流经验式（隐含一般钢管粗糙度，非理想光滑管公式），3e3 ≤ Re ≤ 3e6；2300–3000 过渡区与 Re > 3e6 两端回退 Colebrook，并写明所用口径 |
| 手填 | 直接取输入的 λ | 优先级最高：只要求 u（由 Q、d 算得）、L、Σζ 与手填 λ；密度、粘度仅用于 Re 复核，缺了也不阻断 Σhf |

手填值字段为 lambda_manual：保存层只接受 0.0001 ≤ λ ≤ 1.0 的有限数；λ ≤ 0、空值、NaN/Inf 在计算层按缺项处理（该侧 Σhf 随之留空），不会当作 0 代入，也不回退自动口径。method_note 在缺密度或粘度时写「手填 λ:缺密度或粘度,Re 未计算」，有 Re 时写「手填 λ:λ 由人工给定,Re 仅作复核」。页面管段提示（tooltip）会标出本次所用口径与备注；当前 Excel 泵表与 AI 分析包泵表未单列 λ 口径字段。

λ/Re 的粘度来源：按 6.6 节，管段手填 mu_cp 优先；未手填时两侧共用泵进口流股的 Aspen MUMX 粘度，排出侧不会改读出口流股的 MUMX。因此同一台泵两侧的默认粘度相同，只有逐管段手填才会不同。

两相管段没有专用阻力模型：单侧管段计算不检查 vap_frac，也没有两相拦截或告警；两相吸入/排出管段仍按单相达西公式计算 Σhf——混合密度取 m/Q，粘度按 MUMX 下钻结果：有 TOTAL 取混合总粘度，无 TOTAL 且仅有 LIQUID 时取纯液相粘度（或采用管段手填值）。单相模型通常会显著低估两相管路压降，算出的设计扬程 H 仅作参考，必须另做两相专项核算（见表 11-1）。

### 6.4 绝对粗糙度

默认 ε = 0.05 mm（手册常见取值 0.03–0.1 之间），只在 Colebrook 公式里以 ε/d 进入，ε 与 d 同取 mm（比值无量纲，不随单位制变化）。当前版本没有把粗糙度写进管段记录，实际计算恒用默认值。

### 6.6 粘度的来源与手填

每侧粘度优先级：管段记录手填 μ > 泵块进口流股 Aspen 粘度 > 空。手填时标「手填」，否则标「Aspen」。注意两侧共用同一个 Aspen 粘度（都是进口流股的），排出侧不会改读排出流股的粘度；需要区分时逐侧手填。

仅自动口径（Colebrook / 顾毓珍）执行「层流优先于口径」与「缺粘度判空」：Re < 2300 时改取 λ = 64/Re；粘度缺失时该侧 Re、λ、Σhf 全部为空，状态为未填，缺项列「粘度」；此时应重读带 MUMX 物性集的模型，或直接手填。重读工况不会覆盖手填值。手填 λ 不属于本节：其优先级、缺密度/粘度不阻断 Σhf、不被 64/Re 覆盖，统一见 6.3 节；本节只说明粘度来源与自动口径的缺粘度判空。

## 7 轴功率、效率与建议电机

### 7.1 建议电机与分段裕量

建议电机的基准功率与裕量分开处理：先确定用哪一口径的轴功率作基准，再按基准功率所处的功率段取工程分段裕量。1.25 / 1.15 / 1.10 与 22 / 55 kW 两个分段点参考 API 610 / GB/T 3215-2025 的驱动机额定功率裕量惯例，但本工具只对单工况点的基准轴功率做工程简化选档，未结合泵 Q-H 曲线校核末端最大功率与介质物性波动，不构成标准符合性验证；按基准功率分档而不是先乘裕量再跨段，以避免边界跳变（见 13 章表 13-1）。效率 CEFF 参与设计扬程口径的 design_kw 计算，因而参与电机选档；CEFF 缺失或 ≤0 时 design_kw 为空；除反向守卫已命中外，电机回退 Aspen 口径。

> P_need = P_基准 / η_传动 × m(P_基准) ； 建议电机 = 档位表中第一个 ≥ P_need 的值（m 为按基准功率取的分段裕量）
>
> η_传动：直联 1.0，皮带约 0.95；P_基准 为设计轴功率或 Aspen 折回轴功率；分段裕量按基准功率判断，不按乘完裕量后的需求功率

三段电机裕量按基准功率 P 判断：P < 22 kW 取 1.25；22 ≤ P ≤ 55 kW 取 1.15；P > 55 kW 取 1.10。边界归属为：22.0 kW 落入中段（1.15），55.0 kW 仍在中段，只有 P > 55 kW 才降为 1.10。分段点用基准功率判断，避免「先乘 1.25 再跨段」的边界跳变。若调用方已明确给定裕量，则按给定值计算，以保证同一功率在不同入口下口径一致；页面与导出路径不直接传裕量，统一走分段规则。

GB/T 3215-2025 7.1.4 还规定：所提供的最小可接受电动机额定功率为 4 kW；如果按 4 kW 会明显导致电动机容量过大，替代方案应提交买方批准。本工具不把低于 4 kW 的档位静默隐藏，也不自动抬到 4 kW：仍按上述分段规则输出工程档位，但在 `motor_note` 中写明「如项目执行 GB/T 3215-2025 需买方批准（7.1.4 最小可接受值 4 kW）」。项目未取得买方批准时，应以 4 kW 作为最低选型。另需确认工具的「设计点轴功率」就是标准所说的「泵额定点轴功率」；若两者不是同一工况，表 12 的百分比不能直接套用。

档位共 27 档：0.55、0.75、1.1、1.5、2.2、3.0、4.0、5.5、7.5、11、15、18.5、22、30、37、45、55、75、90、110、132、160、200、250、315、355、400 kW。250 与 315 kW 之间没有 280 kW 一档：档位序列取自工程常用电机功率，不是某个标准的原文；需要 280 kW 规格时按 315 kW 档选取。超出上限返回空并提示所需功率。

边界附近的保守性：裕量按基准轴功率分段（P < 22 kW 1.25；22 ≤ P ≤ 55 kW 1.15；P > 55 kW 1.10），22.0 kW 与 55.0 kW 两个分段点都归中段；基准功率刚过 22 kW 或 55 kW 时只降一档裕量，取档仍向上取整。因此不会把电机选小；代价是少数工况（基准功率紧贴 18.5、22、55 kW 等分段点且相邻档位间距较大时）可能多升一档，属可接受的工程保守。

### 7.2 基准功率优先级与回退规则

基准优先级（页面参数卡、选型台账、页面设备表与 Excel 泵表、AI 包 pumps.csv 均读取 totals.motor）：

- 前置守卫 · 反向/自流：两侧管段齐全且设计扬程 H ≤ 0 时，直接不选电机，power_source 写「反向/自流工况」，并说明「设计扬程 … m ≤ 0」；此时不回退 Aspen 轴功率，不拿 Aspen 的正功率把一个反向工况选成电机。

- ① 设计扬程口径：前置守卫未命中、两侧管段齐全、进口非两相、design_kw > 0 时，用设计扬程 H（未乘 1.1 的 design_head_m）、吸入流股体积流量、2.3 节密度与 CEFF 算出的 design_kw 作基准。H 的 1.1 只用于选型扬程 H_选型，不进入电机功率，避免与分段电机裕量重复叠加。

- ② 回退 Aspen 口径：管段未齐、缺效率 CEFF、两相进口、缺流量/密度或 design_kw 不可用时，改用 Aspen 轴功率。优先 BRAKE_POWER；缺值时才回退 ELEC_POWER × 0.95。power_source 会标注「Aspen压升口径（管段未齐/缺效率/两相进口…）」等具体原因，不静默切换。若 BRAKE_POWER 存在且 ≤ 0，直接在本回退分支判反向并说明，不会转用 ELEC_POWER；只有 BRAKE_POWER 为空才走电功率折算。BRAKE_POWER 为空时先取 ELEC_POWER × 0.95；折算后仍 ≤0 同样不选电机，note 仍写「Aspen 轴功率 … kW ≤ 0」；两者都为空才报「缺 Aspen 轴功率,不选电机」。

工程警示：两相进口落入回退分支时，该电机建议只是借用 Aspen 轴功率给出的功率档参考，不代表离心泵可以在含气/两相进口工况下安全运行。NPSHₐ 与 design_kw 此时已被拒算，汽蚀与两相输送能力均未校核；不得把这条回退结果当作「两相工况可用」的结论，真实两相工况须按泵厂家两相性能或专项试验另行确认。

design_kw 使用吸入段流股流量，check_kw 使用泵块 VFLOW 与压升扬程，前者参与电机选档，后者仍只作 Aspen 压升口径的照会。偏差判据为 abs(VFLOW − q_in) > 0.01 × q_in（前提是两者均非空且 q_in > 0；分母固定取吸入流股流量 q_in，严格大于 1%，恰好 1% 不报），命中时页面提示 VFLOW 与进口流股流量不一致，不静默二选一。

Aspen 轴功率的折回口径：BRAKE_POWER 本身就是轴功率，直接作基准；只有回退读到 ELEC_POWER 时才先乘电机效率 0.95 折回轴功率。电机铭牌标的是轴输出功率，因此轴功率到电机功率只除传动效率再乘裕量，不除电机效率；混用会把档位系统性放大 1/0.95。传动效率界面固定按直联 1.0，无输入入口。

上述 ELEC_POWER × 0.95 隐含一个前提：Aspen 的 ELEC_POWER 已按约 95% 的电机效率计入（电功率 ≈ 轴功率 ÷ 0.95）。0.95 是内置电机效率常量（见表 13-1），不是从模型读取的效率值；模型的电机效率若不同，这一折算需要复核。Aspen Plus 泵模块未设驱动机效率时默认按 1.0 计（此时 ELEC_POWER = BRAKE_POWER）；若回退至该分支且模型未设电机效率，乘 0.95 会使折算轴功率偏低约 5%。

输出一致性：页面参数卡、选型台账、页面设备表、Excel 泵表与 AI 包 pumps.csv 都读取同一组电机建议字段；Excel 泵表与 AI 包 pumps.csv 均含「电机功率口径」列（取 power_source），各出口按该字段直出，不自行重算。Word 报告不含电机建议：报告里的泵只有能量衡算表的一行，其 W 列是能量衡算给出的机械功（轴功率），与这里的「建议电机功率」不是同一个量，不能互相引用。

### 7.3 照会轴功率 P_估 与对账边界

另给一个照会值（check_kw 不参与电机选档）：

> P_估 = ρ·Q·H·g ÷ (3.6×10⁶·η)
>
> P_估 kW；ρ kg/m³；Q m³/h；H m；g m/s²；η 为 0–1 的小数（3.6×10⁶ 是把 m³/h 与 kW 对齐的换算系数）

同式有两组互不混用的输入：check_kw 用 Q = 泵块 VFLOW、H = 压升扬程 HEAD_CAL；design_kw 用 Q = 吸入段流股体积流量、H = 设计扬程 H（仅两侧管段齐全时给）。ρ 同取 2.3 节密度，η 取 CEFF。design_kw 用于电机设计口径，check_kw 只用于与 Aspen 轴功率互校；两者都不含粘度修正与泵型效率曲线。check_kw 的 Q 固定取泵块 VFLOW，不读进口流股 vol_flow；后者缺失只影响 design_kw 的 Q 与两侧水力，不影响 check_kw。不要把 check_kw 的 H 与 design_kw 的 Q 交叉组合，那既不是泵块口径，也不是管段口径。

与 Aspen 轴功率对账时先统一密度：Aspen 的 HEAD_CAL 按泵块密度反算，而 P_估 沿用 2.3 节密度（单相优先取流股 m/V）。两套密度偏差较大时，check_kw 会相对 Aspen 轴功率产生约 ρ_stream / ρ_pump 的系统性偏差，不可直接拿 check_kw 否定 BRAKE_POWER；应先按 2.3 节用同一密度复核压升扬程。

H ≤ 0 时的照会值：轴功率公式不拦截负扬程，H ≤ 0 时 design_kw 会按原式保留负号（0 或负值，表示反向/自流工况参考）；而 check_kw 独立按压升扬程 HEAD_CAL 计算，两者正负号可能不同。不要用一个的符号去反推另一个。

含气/两相进口（汽化率 >1e-4）的照会值一律为空：check_kw 与 design_kw 都返回空，并给 note = 含气/两相进口不计算轴功率照会；电机因此走 Aspen 回退口径。含气/两相流体具有可压缩性，不能套用不可压缩单相液体的扬程功公式；气液滑移与气缚会导致泵水力效率严重衰减，若改用纯液相密度乘两相总体积流量，也会系统性高估 P_估。因此照会值无工程意义，宁可留空；单相与边界 1e-4 仍照常计算。

反向工况下 HEAD_CAL 与压升为负都属正常，原样显示，不取绝对值、不判异常。

## 8 选型台账与三态判定

### 8.1 判据

> NPSHᵣ + 余量 ≤ NPSHₐ(修正) → 满足；否则不满足
>
> 等号成立算满足；比较的是修正值，进口基准值只作对照

判定结果只有三态：满足、不满足、无法判定。台账同时给出理由文本，形如「NPSHᵣ 3 + 余量 0.5 = 3.5 m ≤ NPSHₐ(修正) 4.2 m（进口基准值 6.7 m）」。若进口 vap_frac 为空，三态照样给，但理由末尾追加「缺汽化率，暂按液相估算，请复核」；这表示结论建立在液相假设上，不能当作已确认的单相选型结论。

> **注：** 术语区分：进口基准值 = 未扣吸入段 ΔZ 与 Σhf 的 NPSHₐ；装置有效 NPSHₐ（修正值）= 扣完后的值。三态判据只用修正值，基准值只作对照。

### 8.2 余量的默认值与可调范围

未填时按建议值 0.5 m 参与判定，并置「余量为默认值」标记；人填了就用填的值。建议区间 0.5–1.0 m，但接口不强制落在区间内。整份提交、全空即删行。

### 8.3 无法判定的分支顺序

```text
1 含气/两相进口（汽化率 >1e-4）→ unknown，理由「两相进口不计算 NPSHₐ，无法判定」
2 收集缺项：p_v、进口压力、密度、NPSHₐ(读数不完整:非有限值拦截或基础 NPSHₐ 判空)、吸入段阻力/位压头
3 缺项非空 → unknown，理由「缺 X、Y，无法判定」
4 否则若 NPSHᵣ 为空 → unknown，理由「缺 NPSHᵣ，无法判定」
5 否则按 8.1 判 ok / bad
```

p_v 缺失不会被进口压力顶替，也不会默认「不汽蚀」；NPSHᵣ 为空时不拿建议值或同类泵值替代。

### 8.4 台账能说明什么、不能说明什么

台账记录的是「选了什么」：型号、台数、NPSHᵣ、余量与电机。它不宣称「选得对不对」——工具没有 Q-H 曲线与型谱库，能核对的只有 NPSH 这一条。换工况时自动带出上次的选型，并用当前工况的修正 NPSHₐ 重算三态。

## 9 两侧管段的数据流

### 9.1 一份共享记录

泵面板的「设计扬程 / 管路阻力」与管道页共享同一条流股的管段记录（按模型 + 流股唯一），不另存一份 L、Σζ、内径。管道页看到的人工 DN、手填粘度与管件，就是泵面板读到的同一份。

人工 DN / 自定义规格的完整规则见 9.4 节；此处只记与泵侧相关的一条：生效规格与管道页返回行、导出表及 V2/V3 校核同源，泵侧不再另存一份。

数据流分四步，三条出口（页面、Excel、AI 包）共用同一份结果，Word 报告只取其中的泵轴功率进能量衡算：

1. 取数：管道页参数 + 流股/设备读数 + 该流股的 pipe_run 记录（人工 DN、手填粘度、管件）；
2. 管道构建：得到生效 DN、内径与流速（人工规格在此覆盖自动选档）；
3. 单侧管段计算：逐侧算 u、Re、λ、Σhf 与关联状态；
4. 整泵计算：`pump_line.compute` 汇总两侧，给出压升扬程合计、设计扬程、修正 NPSHₐ 与三态。

页面、Excel 泵表与 AI 包 pumps.csv 三条出口均调用第 4 步的同一函数，取同一组数；Word 报告仅在能量衡算表中读取泵轴功率，不输出上述泵选型与告警字段。

### 9.2 存什么、不存什么

pipe_run 只存输入：L、Σζ、管件明细、λ 口径与手填值、ΔZ、人工 DN 或自定义外径壁厚、手填粘度、备注、版本号。流速、雷诺数、λ 数值、Σhf、自动 DN、内径、设计扬程、选型扬程、NPSHₐ 与三态全部实时算，不落库。

### 9.3 乐观锁

保存管段时带「读到的版本号」，与库内版本不一致返回 409 并提示刷新重试；每次成功保存版本加 1。全空（无管件、无备注、无数值、无口径）时删行。从同模型旧工况沿用过来的记录只回显、不回写，版本号在响应里置 0，避免每次保存都冲突。

### 9.4 人工 DN 与自定义规格

选定人工 DN，或同时填了自定义外径与壁厚后，该管段以人工规格覆盖管道构建的自动选档结果，直到点「恢复自动」。人工 DN 的壁厚不沿用自动档位，而按该外径与管道页的设计压力、许用应力重算，并与管道页共用同一套壁厚路由（材质表 1/表 4、PN 保护、R1E、真空外压）；其中 R1E 是项目专用、非标准公式（不声称标准符合性），且仍受 Pd ≤ 10.0 MPa 守卫，超过时回到通用公式加 PN 整档保护。R1E 路径的负偏差固定为 12.5%（除以 0.875 预先折入所需壁厚），圆整与校核阶段 C1 = 0，不会二次扣减。该人工规格同时进入管道页、管道导出表与 V2/V3：自定义规格按 C1=0、按新外径重算 t_required_mm，V3 若发现薄壁不足仍会报 error；两路径的负偏差语义统一见《管路选型计算说明书》5.4.2 节。保存层要求 2×wall < od，不满足返回 400；已有数据中的异常行不阻断读取，运行时取不到有效内径就判「无法关联」，原因固定「没有可用的管内径」。缺设计压力、缺操作温度或查不到许用应力时不给壁厚，提示改填自定义规格。

若管道构建因 R1E 查不到可用 [σ]^t 等原因早退进 missing（管段记录缺失），仅配 dn_override 仍会因缺设计压力/许用应力落入「无法关联」，并提示改填自定义 od/wall；只有同时填写自定义 od/wall 才绕过缺行继续计算。

人工 DN 不受自动选档跳过规则限制：前端下拉从 DN15 起，可直接选 DN65 / DN125；API/库层面接受 DN_TO_OD 中任意档位（含 DN10）。页面不提供 DN10，但直接经接口或库写入 dn_override=10 仍会被接受。

改管道页参数会先算影响：涉及几台泵、设计扬程最大变化多少、哪些 DN 会变；预览确认后才写入，避免「拖一下参数悄悄改掉一批结论」。

### 9.5 缺一侧与多流股

状态列的口径：下表「状态」指该侧管段自己的关联状态，不是整泵状态。一侧已关联、另一侧缺失时，泵仍可能整泵不给设计扬程与选型扬程。L 或 Σζ 缺失会让该侧 Σhf 为空、状态判「未填」；ΔZ 不影响关联状态——仅排出侧 ΔZ 缺失时该侧仍标「已关联」，修正 NPSHₐ 仍可算（只扣吸入侧），但设计扬程 H 与选型扬程为空。

**表 9-1 两侧流股关联状态（状态列为单侧）**

| 情况 | 状态 | 表现 |
| --- | --- | --- |
| 恰好一条候选流股 | 已关联 | 自动使用 |
| 人工指定且在候选内 | 已关联 | 使用指定流股 |
| 没有候选 | 缺失 | 提示泵缺进口/出口流股，无法关联管路 |
| ≥2 条且未指定 | 待指定 | 列出候选，要求指定，绝不按名字猜 |
| 已关联但 L/Σζ 未填 | 未填 | L 或 Σζ 任缺：该侧 Σhf 即为空（只填 L 不够），整台泵不给设计扬程与选型扬程 |
| 已关联、L/Σζ 已填但吸入侧 ΔZ 缺失 | 已关联 | Σhf 可算出，但修正 NPSHₐ、设计扬程 H 与选型扬程均为空 |
| 已关联、L/Σζ 已填但仅排出侧 ΔZ 缺失 | 已关联 | 修正 NPSHₐ 仍正常计算（只扣吸入侧），但设计扬程 H 与选型扬程为空 |

### 9.6 旧单一 Σhf 的迁移

旧数据中每台泵只有一组 L/Σζ/Σhf。检测到旧数据时提供迁移向导：归吸入、归排出、或标为「两侧合计」。归某一侧时旧 ΔZ 置空，要求两侧分别补标高差；标为合计时修正 NPSHₐ 仍判无法判定，不拿合计值冒充吸入侧。旧手填内径不沿用，管径改由管道页统一选型。

## 10 三条出口的一致性，与 Word 报告的边界

泵页、Excel 泵表与 AI 分析包的 pumps.csv 取同一组计算结果；Word 报告只取泵轴功率。Word 报告里的泵只有两处：①「逐设备能量衡算」分组表中的一行，列为 设备 / 侧 / ΣHin|kW / ΣHout|kW / Q 热负荷|kW / W 机械功|kW / 偏差|kW / 判定，其中 W 是泵轴功率；②「全流程能量汇总」里的「泵与压缩机总轴功」一项。报告没有逐台泵参数表（不出 NPSHᵣ、NPSHₐ、H、H_选型、效率、建议电机），也不逐台列 warnings。引用时注意三点：

- 含气/两相进口的 NPSHₐ 由核心函数统一拒算，页面与 Excel / AI 包（三条出口）同为空（Word 报告不含 NPSHₐ 字段，见第 4 章）；

- 页面顶部余量倍率仅影响页面前端展示层，不进入三条出口共享结果，也不改 Word 报告里的轴功率；完整边界见第 5 章；

- 重力加速度统一为 9.80665；顾毓珍公式在 2300–3000 过渡区与 Re>3e6 两端都回退 Colebrook 并标注口径。

## 12 复算示例

以下数据由本工具实算（合成输入），算例 A 与算例 B 的输入彼此独立：算例 A 只复算「一段管」的沿程与局部阻力；算例 B 复算「一整台泵」的 NPSH 与设计扬程，其中的 Σhf 由管段记录直接给出。两段输入彼此独立，A 的 Σhf 不进 B 的算式，避免把「按 L/Σζ 算出的 8.97 m」与「记录里的 1.5 / 3.0 m」混成一笔账。表内数值为四舍五入后的展示值，实际计算按全精度传递；复核时以公式复算值为准，不用表内尾差反推实现。

### 12.1 单管段阻力复算（算例 A）

输入：Q = 100 m³/h，ρ = 900 kg/m³，μ = 1.0 cP，d = 100 mm，L = 50 m，Σζ = 5，ε = 0.05 mm；λ 按 Colebrook 与顾毓珍公式各算一次，用于说明两种口径的差别。

**表 12-1 算例 A：单管段阻力（Q=100 m³/h，d=100 mm，L=50 m，Σζ=5）**

| 量 | 公式与取值 | 结果 |
| --- | --- | --- |
| u | (100/3600)/(π×d_m²/4)，d_m = 0.1 m | 3.537 m/s |
| Re | 0.1×3.537×900/(1.0/1000) | 3.18×10⁵ |
| λ（Colebrook） | 1/√λ = −2log₁₀(0.05/(3.7×100) + 2.51/(Re√λ)) | 0.01813 |
| λ（顾毓珍） | 0.01227 + 0.7543/Re^0.38 | 0.01839 |
| Σhf（Colebrook） | (0.01813×50/0.1 + 5)×3.537²/(2×9.80665) | 8.97 m |
| Σhf（顾毓珍） | (0.01839×50/0.1 + 5)×3.537²/(2×9.80665) | 9.05 m（全精度实算） |

同一几何下，顾毓珍 λ 使 Σhf 由 8.97 m 变为 9.05 m，仅高 0.08 m（约 0.9%）；说明在本例的 Re 与相对粗糙度范围内，λ 口径对最终阻力的影响有限，但不能据此把两种口径混用。

### 12.2 整台泵 NPSH 与设计扬程复算（算例 B）

输入：压升扬程 Hpr = 20 m；进口流股操作压力 2.0 bar（按第 3 章假定视为上游容器操作压力）、p_v = 0.4 bar、ρ = 900 kg/m³；吸入段 ΔZ = +2 m（吸上工况：泵进口高于吸入液面 2 m，沿流向抬升）、Σhf = 1.5 m；排出段 ΔZ = 5 m、Σhf = 3.0 m；NPSHᵣ = 3.5 m、余量 0.5 m。Σhf 两项是记录值，不由算例 A 推出。

**表 12-2 算例 B：整台泵 NPSH 与设计扬程（吸上工况，泵进口高于吸入液面 2 m）**

| 量 | 公式与取值 | 结果 |
| --- | --- | --- |
| NPSHₐ(进口基准) | (2.0−0.4)×10⁵/(900×9.80665) | 18.13 m |
| NPSHₐ(装置有效) | 18.13 − 2.0 − 1.5 | 14.63 m |
| 设计扬程 H | 20 + (2+5) + (1.5+3.0) | 31.5 m |
| 选型扬程 | ceil(1.1×31.5) | 35 m |
| 三态 | 3.5 + 0.5 = 4.0 ≤ 14.63 | 满足 |

**算例 B 续：设计轴功率与建议电机复算**

接上算例 B 的 H = 31.5 m，补充两项输入：吸入流股体积流量 Q = 1200 m³/h、泵效率 η = 0.705（另取 ρ = 900 kg/m³、g = 9.80665 m/s²）。代入 P_估 = ρQH g / (3.6×10⁶ η)：900×1200×31.5×9.80665 / (3.6×10⁶×0.705) = 131.45 kW。这里的 H 是未乘 1.1 的设计扬程，故该值就是设计扬程口径的基准轴功率 design_kw；H = 31.5 m > 0，不触发反向/自流前置守卫，走①设计扬程口径。它落在 > 55 kW 段，取裕量 1.10：131.45×1.10 = 144.60 kW，档位表中第一个 ≥ 144.60 kW 的是 160 kW，于是电机选 160 kW。直联传动效率取 1.0，不再另乘；若用皮带（约 0.95），应先除传动效率再乘分段裕量。

两个“≤0/未齐”分支必须分开：① 两侧管段齐全且设计扬程 H ≤ 0 时，由前置守卫直接不选电机，power_source 写「反向/自流工况」，不回退 Aspen；② 管段未齐（或设计口径不可用）时进入回退 Aspen 口径，若此时 BRAKE_POWER 为 −2 kW，则在该回退分支内判 「Aspen 轴功率 −2.00 kW ≤ 0,反向工况不选电机」，power_source 为「Aspen压升口径（管段未齐）」，同样不转用 ELEC_POWER。

其余口径对照：小功率基准 20 kW → 20×1.25 = 25 kW → 取 30 kW 档（P < 22 kW，1.25 档）；若回退 ELEC_POWER 140 kW，则 140×0.95×1.10 = 146.3 kW → 取 160 kW 档。
