## 约定

- 和 `model/` 一样:`*.apw`、`_<运行ID>.*`、`*.ads` 等全部**不进 Git**(见根目录 `.gitignore`)
- 这个文件夹里只保留本 README
- 打开模型请从这里双击,不要另存到项目根目录,否则运行文件会漏到外面
- 这份模型的运行结果是**有错误的**(T0202 塔发散、T0205 组分平衡不收敛),
  适合当"异常工况"的测试样本;不要拿它当"收敛正常"的参照
