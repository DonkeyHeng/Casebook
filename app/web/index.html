Aspen 物性组配置

物性组只决定 Aspen 在结果中写哪些节点;本工具按节点读数,读不到留空并提示,不取常见值顶替。

  1. 「模拟」页 → 物性组 → 新建物性组 Donkey(实际名称不限,本教程统一按此名说明)。
  2. 添加五项:PL、PBUB(bar)、MUMX(cP)、CPMX(cal/mol-K)、KMX(kcal-m/hr-sqm-K);单位保持默认。
  3. 「限定符」页:相态勾 Vapor 与 Liquid 两列;只勾一侧时,另一相流股读空。
  4. 「模拟」→ 设置 → 报告选项 → 流股 → 物性组:把刚才建的 Donkey 加入右栏。
  5. 重置并运行至收敛 →「读取当前工况」;换热页再点「重新读物性」。
物性默认单位供数给未配置 / 读不到
PBUB 泡点压力bar泵 p_v、NPSHₐ、汽蚀判定p_v 留空;泵页可手填
MUMX 混合物粘度cP管道 Re 与沿程阻力;换热 Re / Pr 与膜系数;泵管路阻力阻力与 h 缺项
CPMX 混合物定压比热cal/mol-K(摩尔基)换热 cp → Pr、膜系数 h、需求面积 A_reqL2 仅给几何与面积
KMX 混合物热导kcal-m/hr-sqm-K换热 λ → Pr、膜系数 h同上
PL 液相压力bar旧布局的 p_v 备用路径;p_v 以 PBUB 为准不影响 PBUB 读数

单位换算:CPMX 为摩尔基,×4.184 → J/(mol·K),再按流股 MW 折 J/(kg·K);KMX ×1.163 → W/(m·K)。单位串认不出时留空并计入「单位未识别」,不做近似替换。

依据 Aspen Plus V15;其他版本菜单名可能不同。无读数时泵 / 换热页均可手填。
