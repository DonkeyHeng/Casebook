管道计算说明

如果你了解管道选型,可以拿这份说明检验算法对不对。 下面十步就是工具算每一根管的完整过程,中间结果全都摆得出来:勾上「显示计算过程」, 表里会多出设计压力、设计温度、许用应力、计算厚度、加裕量后厚度、最小壁厚下限几列; 导出 Excel 的「管道计算书」是同一份数据。挑几条流股照着算一遍即可; 如果结果对不上,请到 GitHub 仓库提 issue(入口见 README 的「参与贡献」), 附上流股名、相态、体积流量和你算出的值,方便定位是口径不同还是算法有误。

如果不了解管道计算,请直接忽略这份说明。 你只需要知道:表里的公称直径和壁厚是工具按固定口径算出来的,不是从 Aspen 读的; 想改口径就改页面顶部的流速与设计压力参数。

计算可能有误,结果仅供参考。 流速取值、壁厚圆整、最小壁厚下限都是约定口径,不同设计院会取不同的数; 工具也不做外压稳定、管长压降、应力与振动校核,管径只做到 DN600(更大的单独列在表尾)。 这些数字不能直接当施工图或采购清单,正式设计请交由设计人员复核。

一、管径计算

步做什么怎么定 / 公式
1判相态 汽化率 < 1e-4 按液体,> 1−1e-4 按气体,其余按气液共存。留这个容差是因为库里实测有 1e-8 量级的痕量汽化率,按 == 0 判会把全液流股误判成两相。
2取流速 液体 1.5、气体 15、两相 8、泵入口 0.8 m/s;泵入口只在该流股进入泵块(方向 in)时生效, 泵出口不沿用这个口径。
3算内径 D = √(4Q / (π·v)),Q 是 Aspen 的体积流量(m³/h 换算成 m³/s)。
4选 DN 从 DN10 起逐档往上试,直到 外径 − 2×壁厚 ≥ 计算内径。 不能按 DN ≥ 计算内径 选 —— 同一 DN 的外径比 DN 大,那样选会系统性偏大。

二、壁厚计算

步做什么怎么定 / 公式
5设计压力 P = (操作绝压 − 0.1013 MPa) × 1.1,下限钳到 1.0 MPa。 表压在 ±0.01 MPa 内按常压算(1.0 bar 绝压不是真空);更低的标真空, 按外压 0.1 MPa 校核 —— 工具不做外压计算。
6设计温度 介质 ≥50 ℃ 视为保温,直接取介质温度;只有 65–80 ℃ 且无保温时折 0.95。
7许用应力 按牌号 + 设计温度查 GB/T 20801.1 表 B.1,缺温度线性内插;低于 40 ℃ 取 40 ℃ 列; 超出表范围不给值(不猜)。
8计算壁厚 t = P·D_o / [2·([σ]·Φ_w + P·Y)],无缝 Φ_w = 1、Y = 0.4。 只有 t < D_o/6 时公式适用,否则标"需另行校核"。
9选壁厚 加上腐蚀裕量后要满足 S − C1 ≥ t + C2(C1 是标准壁厚的负偏差, 按 GB/T 17395 表 8 的 S2-B 档),在这个前提下圆整到规格表里的标准壁厚; 最后再套最小壁厚下限。
10等级号 压力代号 + 顺序号(默认 1)+ 材质代号,设计温度 ≥50 ℃ 再补保温代号 -H。

最小壁厚下限:DN10–25 取 2.0 mm、DN32–100 取 3.0 mm、DN125 起不设限。 承压公式只管"承得住",不管"能不能施工" —— 1.0 MPa 的 DN15 按公式只要 0.07 mm, 圆整到标准壁厚是 0.5 mm,那是换热管/仪表管规格,工艺管道焊不出来。下限只抬高、不降低, 承压需要更厚时仍按承压。所以表里会出现"计算厚度 0.21 / 选定壁厚 3.0"这种组合: 前者是承压所需,后者是被下限托住的施工厚度。

三、口径说明

  • 两相为什么按 8 m/s:保守取法,落在 5–10 m/s 的常用区间内。取低流速会让管径偏大, 若按更高流速选型,管径会相应变小 —— 在参数条上改「两相」即可重算。
  • 液体为什么是 1.5 m/s:常用区间 1.0–2.5 m/s 的中值。不同项目取值不同, 只要在区间内都属正常;在参数条上直接改。
  • 为什么材质不自动判定:腐蚀不是组分清单的函数 —— 浓度、温度、含水量、氯离子 ppm、流速 都会翻转结论(干氯气对碳钢几乎不腐蚀,痕量水就变成剧腐蚀)。用哪种材质由你或材料专业定, 工具只按「管道等级表」一致地套用。
  • 为什么不做管长压降:本期只管"选型",不含管网水力计算;DN 也只做到 600, 更大的会单独列在表尾提示"需并联或专项设计"。

四、校验规则

  • V1 流股编号里的口径与选出的 DN 不一致
  • V2 按选定内径反算的实际流速,超出该相态的推荐区间
  • V3 承压所需壁厚超过所选标准壁厚
  • V4 等级号的压力代号低于设计压力
  • V5 气液共存却按单相流速选型
  • V6 真空流股(按外压 0.1 MPa 另行校核)
  • V7 设计温度超出材料常规使用区间
  • V8 泵出口流股沿用了泵入口流速
  • V9 高温流股却未加保温代号

这些提示只陈述事实,不替你决定怎么改:该加保温、该换材质、该分两路,都是设计判断。

五、数据来源

  • 外径与标准壁厚系列:GB/T 17395-2024 表 1(碳钢)、表 4(不锈钢)
  • 壁厚负偏差:GB/T 17395-2024 表 8,S2-B 档(无缝管按 −12.5%)
  • 许用应力:GB/T 20801.1-2025 表 B.1
  • 壁厚公式与系数:GB/T 20801.1-2025 6.2.1、表 27(Y 值)、4.1.6.2(最小厚度)
  • 压力代号 / 材质代号 / 绝热代号:HG/T 20519.6

标准表的数值属于标准原文,不随公开仓库分发(只在本机 data/ 下);换一台机器要按 docs/pipe-standards-index.md 的页码重新录入。 整理成 CSV 后点本页右上角的「标准表」按钮导入即可,不用重启服务。 录不到时页面会显示"标准表未录入"并列出缺哪张,不会拿 0 算出一张假表。

核对时建议从中间结果入手:设计压力 → 许用应力 → 计算厚度 → 选定壁厚 → DN, 每一步都能独立复算。若发现与预期不符,请到 GitHub 仓库提 issue(入口见 README 的「参与贡献」), 附上流股名、相态、体积流量和你算出的值,便于定位。
