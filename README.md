# Casebook

<img src="assets/app-icon_256.png" width="96" align="right" alt="Casebook 图标">

**将 Aspen Plus 仿真结果转化为可检索、可对比、可导出的本地工程数据工具。**

打开已运行的 Aspen 模型，点击「读取当前工况」，即可在本地网页中一站式查看全流程流股、设备参数、塔板剖面与工艺连接图，支持**多工况对比**、**管路与泵选型辅助**、**一键生成物能衡算报告**，以及导出结构化数据与 AI 分析包。

## 核心痛点与设计原则

Aspen Plus 擅长流程模拟，但在**数据查阅、异常定位与设计报告整理**上并不友好：核对流股组成、对比不同工况热负荷、整理塔板剖面往往需要逐格复制；当流程出现警告或报错时，异常信息分散在收敛块、模块消息与撕裂流中，很难一眼判断「当前结果是否可用、哪些流股被波及」。

Casebook 的设计遵循四条原则：

- **无侵入只读附着**：通过 Windows COM 文件 Moniker 直接附着已打开的 Aspen 实例，全程只调用 `FindNode` 与 `.Value` 读取数值，不启动新会话、不占用额外许可证，也不会修改、重算或保存原模型。
- **本地快照与哈希识别**：每次读取均作为独立工况存入本地 SQLite 数据库（从不覆盖），并通过模型文件内容 `sha256` 哈希识别同一模型，确保多工况对比可追溯、手工录入参数不串库。
- **宁缺勿错，不猜数值**：单位换算逐字段按 Aspen 原始 `UnitString` 执行，认不出的单位或缺失物性（如 $p_v$）一律留空并汇总提示，绝不以 `0` 或估算值顶替。
- **只陈述事实，明确边界**：自动完成三态收敛判定、报错波及反推、全设备焓平衡与规范校验（V1–V13），但只输出客观校核结论，不给出「如何修改模型」的盲目建议，并完整披露计算口径与适用边界。

## 快速开始

### 1. 获取与启动

| 使用方式 | 操作步骤 |
| :--- | :--- |
| **免安装版（推荐）** | 前往 [Releases](https://github.com/DonkeyHeng/Casebook/releases) 下载 `Casebook-windows-x64.zip`（约 40 MB），解压出一个 `Casebook` 文件夹，双击其中的 `Casebook-Desktop.exe` 即可运行：**自带窗口，不依赖浏览器**（根目录附带 `安装说明.txt`）。 |
| **源码运行（Python 3.10+）** | 克隆或下载源码后，双击根目录的 **`start.cmd`** 启动（自动检查依赖、拉起服务并打开应用窗口，关闭窗口即自动退出后台进程）。 |
| **遇到安装或运行报错** | 请查阅详细排错文档 **[docs/install.md](docs/install.md)**（纯文本版见 [`docs/install-text.txt`](docs/install-text.txt)）。 |

**命令行启动方式：**
```bash
git clone [https://github.com/DonkeyHeng/Casebook.git](https://github.com/DonkeyHeng/Casebook.git)
cd Casebook
python -m pip install -r requirements.txt
python -m app.api   # 启动后自动打开应用窗口（默认 [http://127.0.0.1:8000](http://127.0.0.1:8000)）
```

### 2. 三步上手流程

1. **运行模拟**：在 Aspen Plus 中打开 `.apw` 模型并完成一次完整计算。
2. **读取工况**：在 Casebook 左侧栏点击 **「读取当前工况」**，观察阶段进度条完成全流程采集（100 条流股约需 15–40 秒）。
3. **查阅与导出**：在左侧栏切换查看流股、设备、流程图、管道选型或衡算报告；点击右上角导出 Excel 台账、Word 报告或 AI 分析包。
   > *提示：首次使用管路选型功能前，需在「管道」页右上角点击 **「标准表」** 导入自备国标 CSV 数据（详见 FAQ 第 3 条）；如需按特定介质指定材质与腐蚀裕量，可在「等级表」中配置规则。*

### 3. 离线体验（无需 Aspen）

首次打开软件时本地数据库为空，首页会显示引导提示。仓库内置了一组包含 **121 条流股、77 个模块、214 条连接、401 条塔板记录与 7 台泵**的真实异常工况快照（含 `T0202` 塔干涸、`T0205` 组分不收敛），可用于完整体验界面与诊断逻辑：

- **使用免安装版**：双击 `Casebook-Desktop.exe`，在首页点击 **「载入示例工况」** 按钮（或运行 `Casebook-Desktop.exe --sample`），原库会自动备份为 `cases.db.bak`。
- **使用源码**：
  ```bash
  cp data/cases.db data/cases.local.db   # 若已有本地数据请先备份
  cp samples/case-23-error.db data/cases.db
  python -m app.api
  ```
  *示例数据详情见 [`samples/README.md`](samples/README.md)。*

## 架构与功能全景（8 大模块 · 61 项能力）

Casebook 围绕 **「读—存—看—算—报—出—跑—测」** 八个层次构建，所有计算与展示均基于同一份本地快照同源驱动：

| 层次 | 覆盖范围 | 核心职责 |
| :--- | :--- | :--- |
| **1. 数据采集与判定** | COM 只读附着、全流程提取、后台进度、单位归一、三态判定、波及分析 | 解决「数据从哪来、可不可信、哪些流股受报错波及」 |
| **2. 本地存储与识别** | SQLite 多工况快照、内容哈希身份识别、历史工况离线回算迁移 | 解决「数据存在哪、换工况会不会串、规则升级如何回算」 |
| **3. 界面浏览与可视化** | 首页结论卡、流股与组成抽屉、设备分族九页签、塔剖面、交互流程图、多工况对比 | 解决「人怎么快速看懂流程与定位异常」 |
| **4. 工程计算** | 泵参数与 $\text{NPSH}_a$、设计扬程与阻力、选型台账、十步管路选型、V1–V13 校核 | 将仿真读数转化为带口径说明的选型参数与风险校核 |
| **5. 衡算与报告** | 工段（界区）边界确认、界区+逐设备两层物料衡算、能量汇总、Word 两册独立报告 | 面向课程设计与工程文档，生成可直接排版的物能衡算书 |
| **6. 导出与外部集成** | 整本 7–8 表 Excel、按设备分类 Excel、AI 分析包（`.zip`）、十列管道一览表、CLI 入口 | 满足设计存档、报表粘贴与大模型辅助选型/分析需求 |
| **7. 运行环境与安全** | 零构建 HTTP 服务、自带窗口壳（WebView2，不依赖本机浏览器）、本地请求护栏、单点版本与手动检查更新、数据隔离 | 保障本地运行安全、数据不离机、升级不丢历史库 |
| **8. 工具链与质量保障** | 910 条离线回归自测（含 COM 节点树夹具回放）、无头双主题界面巡检、敏感信息扫描、字段探针、塔异常诊断 | 确保判定与计算口径改动可验证、开源发布不泄密 |

### 核心功能详解

#### 数据采集、判定与存储
- **全流程采集与进度反馈**：后台线程独立初始化 COM 并按「流股 → 设备 → 判定」分阶段采集，实时返回已处理条数与对象名（100 条流股约 15–40 s，1,000 条流股约 76 s）。
- **单位归一与缺口诊断**：统一换算为 `℃ / bar / kg·h⁻¹ / kmol·h⁻¹ / m³·h⁻¹ / kW / m²`，同时保留 Aspen 原始值与原始单位；未识别单位留空并在首页与提示条列出缺口明细。
- **单一入口三态判定与波及分析**：集中合成运行状态码、`BLKSTAT` 与撕裂流，输出 `正常 / 告警 / 报错` 三态结论及 Aspen 原文提示（不收敛工况照常入库并标黄，统计与对比中默认隔离）；自动沿连接拓扑反推报错设备波及的进出口流股并标记「不可用」。
- **全设备焓平衡自检**：按设备族执行 $\Delta H = \Sigma H_{\text{出}} - \Sigma H_{\text{进}}$ 自检——加热器/闪蒸对热负荷（相对 1% 且绝对 0.5 kW）、双流股换热器校冷侧、泵/压缩机校 $\Delta H$ 与轴功率比值、塔校首级冷凝器与末级再沸器之和、反应器校反应热、绝热设备按最大焓流 0.5% 判零。
- **组分字典与按需读取**：从模型文件 `COMPONENTS MAIN` 与 `DSET CASN` 配对解析 CAS 编号（避免不同模型组分 ID 串名），显示「中文名 + CAS」并支持自定义组分手动补录；流股组成默认点击按需读取（单条约 264 ms）并缓存，也可在读取前勾选「读全部流股组成」一次性采集各组分质量流量。
- **内容哈希身份与历史回算**：基于模型文件 `sha256` 哈希关联同模型不同工况，支持一键沿用上一工况的 $p_v$ 与工段边界；规则更新后运行 `python -m tools.repair_cases --apply` 即可在库内直接重算判定、焓平衡与派生参数，无需重开 Aspen。

#### 界面可视化与多工况对比
- **设备分族九页签**：将数十种 Aspen 模块收敛为**塔 / 换热 / 分离 / 反应 / 泵 / 涡轮机 / 流体输送 / 混合分流 / 其他**九个页签（自动按位号 `P` / `K` 前缀区分泵与透平），默认按「报错 → 告警 → 正常」排序。
- **塔逐板剖面与交互流程图**：塔设备支持打开逐板温度、压力、气液流量与热负荷曲线（与数据表双向联动定位干板或温度跳变）；流程图自动生成分层拓扑，支持滚轮缩放、点击聚焦上下游两层、键盘快捷键（`+ / − / 0 / Esc`）及导出矢量 **SVG** / 高清 **PNG**。
- **多工况对比**：任选两个历史工况并排对比流股或设备参数（`基础值 / 对比值 / 差值`），自动高亮状态变更与焓平衡结论变化，缺失项留空不补零。
- **外观与无障碍**：支持跟随系统 / 浅色 / 深色三态主题、应用窗口位置与尺寸记忆、关窗自动停止后台服务，并补齐语义地标、键盘方向键滚动与 `Esc` 焦点还原。

#### 工程计算（泵与管路选型）
- **泵参数与 $\text{NPSH}_a$**：自动提取流量、扬程（优先 `HEAD_CAL`）、效率、轴功率、粘度与进出口状态，自算装置侧有效汽蚀余量 $\text{NPSH}_a = (p_{\text{进}} - p_v)\times 10^5 / (\rho g)$（跳过不可靠的 Aspen 原生 `NPSH-AVAIL`；进口为两相流时自动跳过并说明原因），并按「轴功率 ÷ 传动效率（直联 1.0）× 裕量 1.10」向上匹配建议电机功率档位（只有 Aspen 只给 `ELEC_POWER` 时才按 0.95 折回轴功率）。饱和蒸气压 $p_v$ 支持 Aspen 自动读取（兼容 V11 / V12.1+ 节点布局）、逐台手填及同模型跨工况一键沿用。
- **设计扬程、管路阻力与选型台账**：在泵抽屉内区分「压升扬程」与「设计扬程」，输入位压头 $\Delta Z$ 与管长/管件系数 $\Sigma\zeta$ 后，自动引用「管道」页内径与进口粘度，按 Colebrook 迭代 / 顾毓珍公式 / 手填 $\lambda$ 计算 $\Sigma h_f$ 及圆整后的选型扬程 $\lceil 1.1 H \rceil$。选型台账持久化人工选定的型号、材质、配套电机与 $\text{NPSH}_r$，校核结论随当前工况实时刷新。
- **选型辅助与 AI 提示词**：支持一键打开中联泵业选型页（不外传任何工况数据）、一键复制选型参数行，以及一键复制针对当前泵表的 **AI 选泵提示词**（与分类导出的「选泵提示词」工作表、AI 数据包 `pump_prompt.md` 三处同源）。
- **管路选型十步计算与 V1–V13 校核**：对每条有效物料流股自动执行「判相态 → 定介质代号 → 选流速 → 算内径并圆整 DN（`DN15`–`DN1000`，超 `DN600` 改焊接管，`DN1000` 留 5% 容差）→ 定设计温压（操作温度 ≥ 0 ℃ 时取 +20 ℃、< 0 ℃ 时取 −20 ℃；设计温度 ≥ 65 ℃ 加保温 `-H`，低温加保冷 `-C`）→ 查许用应力 → 按 GB/T 20801.1-2025 6.6.1.2 算承压壁厚并叠加腐蚀裕量、负偏差与工艺最小壁厚下限 → 生成管道等级号」。同步运行 **V1–V13** 规范校核（涵盖泵入口/汽蚀限速、真空绝压 `< 95 kPa` 判定与长圆筒外压失稳筛查、两相流均相动压头限速及大口径分层流预警、高压高温不锈钢升 `R1E`、非标流水号、零流量等）。

#### 物能衡算与多格式交付
- **工段界区与两层物料衡算**：按设备名段号自动推演工段草稿，经人工确认后分别执行**界区衡算（工段 $\Sigma\text{进界} = \Sigma\text{出界}$，主表）**与**逐设备衡算（辅助表）**，相对容差 `0.5%`（小于 `1 kg/h` 的极小流量自动豁免），生成流股为列的**物料平衡宽表**与按年运行 `8000 h` 折算的年化量总结表（`t/a`）。
- **独立双册 Word 衡算报告**：一键导出《物料衡算报告》（冷蓝主题）与《能量衡算报告》（暖砖红主题），两册各自成文，包含封面、目录、页眉页码与三线表，超差行浅红底高亮，附注自动列出本册需人工插入的图表。
- **多形态数据导出**：
  - **整本 Excel 台账**：含 7 张工作表（概要 / 流股 / 设备 / 泵 / 连接 / 塔剖面 / 管道计算书；存在未选型流股时另加一张明细表）。
  - **按设备分类 Excel**：与当前页签列完全一致；泵分类附带全部选型核心列与「选泵提示词」工作表。
  - **十列《管道选型一览表》Word**：对齐设计院附录版式（三线表、小五字号、独立「校核备注」列），亦可命令行输出逐项审计明细。
  - **AI 分析数据包（`.zip`）**：内含 `README.md`（数据字典与运行结论）、`metrics.csv`、`streams.csv`、`blocks.csv`、`case.json` 及条件生成的 `column_profiles.csv`、`composition.csv`、`pumps.csv`、`pump_prompt.md`、`pipe_schedule.csv`，空值严格为空字符串、保留原始值与单位，可直接投喂任意大模型分析。

## 工程口径与适用边界

将本工具输出用于课程设计、竞赛或工程参考时，请务必核对以下边界与前置条件：

- **只读分析工具**：不执行闭环流程优化，不向 Aspen 写回任何参数。
- **前置条件依赖**：
  - 管路选型需自行导入 **GB/T 17395-2024** 与 **GB/T 20801.1-2025** 的三个 CSV 数据表；
  - 泵 $\text{NPSH}_a$ 需模型配置 `pv` 物性集输出泡点压力（或人工在页面填入）；
  - 物料衡算报告需先在页面确认工段（界区）边界，且需读取流股组成才能输出各组分质量流量。
- **管路选型边界**：当前支持最大公称直径至 **DN1000**（超限流股单独标注「需并联或专项设计」）；真空外压失稳（V11）仅为长圆筒弹性屈曲筛查壁厚下限，**不替代正式外压容器/管道应力计算**；管段沿程与局部阻力 $\Sigma h_f$ 目前仅在泵参数悬浮窗的吸入 / 排出两侧管段内计算，暂不对全厂管网做水力压降平衡；两相流采用 `8 m/s` 基准流速并叠加均相动压头限速，结果偏保守，引用时需注明口径。
- **泵选型边界**：仅计算装置侧有效汽蚀余量 $\text{NPSH}_a$，泵必需汽蚀余量 $\text{NPSH}_r$ 需查阅厂商样本并填入台账对比（默认建议余量 `0.5 m`）；「建议电机」按常用电机功率档位表向上圆整，属于工程估算参考值；反向工况（轴功率 $\le 0$）不匹配电机。
- **实测覆盖范围**：COM 采集与泵参数已在 Aspen Plus V15（`MET` / `METCBAR` 单位集）下实测验证，`ENG` 单位集按定义推导尚未经过真实模型实测；进口两相泵的拒算逻辑已通过单元测试覆盖。

## 环境要求与本地数据规范

### 运行环境
- **操作系统**：Windows 10 / 11（依赖 Windows COM 接口，不支持 macOS / Linux）。
- **模拟软件**：Aspen Plus **V15**（实测版本，兼容性覆盖 V11 / V12.1+ 常见节点布局），需自备正版许可。
- **运行会话**：必须在**真实本地桌面会话**中运行，且 Casebook 需与 Aspen Plus 保持**相同的管理员权限级别**。
- **浏览器**：Edge / Chrome 等现代浏览器（前端零构建，无需 Node.js）。

### 本地数据与安全隔离
- **目录隔离**：静态网页与图标打包在资源目录，所有用户数据固定存放在可写 `data/` 目录下（工况库 `data/cases.db`、国标 CSV `data/preview/std/docx/*.csv`、管道等级配置 `data/config/piping-classes.json`、工段配置 `data/config/sections.json`），**均不纳入 Git 版本控制，升级覆盖安装时请务必保留 `data/` 目录**。
- **本地服务安全护栏**：内置 HTTP 服务仅监听本机回环地址，校验 `Host` 白名单防 DNS rebinding，所有写请求校验自定义标记头与 `Origin` 防跨站请求，并对请求体设置上限（普通 JSON `256 KB`、标准表导入 `16 MB`），损坏或超限请求一律拒绝，绝不覆盖已有配置。

## 常见问题 (FAQ)

<details>
<summary><strong>1. 点击「读取当前工况」提示无法连接到 Aspen？</strong></summary>

请依次排查以下三点：
1. 确认 Aspen Plus 已打开并加载了目标模型文件（`.apw` / `.bkp`）。
2. 确认软件运行在本地真实桌面会话中（部分远程桌面/沙箱会话无法访问运行对象表）。
3. 确认 Casebook 与 Aspen Plus 的权限一致（不要一个以管理员身份运行、另一个以普通用户运行）。
若仍无法连接，可运行探针脚本 `python tools/probe_aspen.py` 排查 COM 接口状态。
</details>

<details>
<summary><strong>2. 为什么流股组成需要点击后才加载？</strong></summary>

完整读取一条流股的组成（气液相摩尔分数 + 各组分质量流量）需要发起 54 次 COM 调用，121 条流股全量读取会使耗时从数秒增加到数十秒。因此软件默认采用「点击按需读取 + 本地缓存」策略（首次约 264 ms，缓存后 0 ms）。
- **提示**：若你需要导出包含「各组分质量流量」的《物料衡算报告》，请在读取前勾选侧栏读取按钮下方的 **「读全部流股组成」**（否则报告中仅按摩尔流量输出）；若读取后 Aspen 仍未关闭，也可运行 `python tools/fill_composition.py` 批量补齐。
</details>

<details>
<summary><strong>3. 为什么管路选型提示「标准表未录入」？如何配置？</strong></summary>

管路选型依赖 **GB/T 17395-2024**（表 1、表 4）与 **GB/T 20801.1-2025**（表 B.1）中的管径壁厚与材料许用应力数据。**由于国标原文受版权保护，仓库与安装包内不包含这些数据表。**

**三步配置流程：**
1. 自行获取上述国标文本，整理为三个 UTF-8 编码的 CSV 文件：`t1-17395-table1.csv`、`t4-17395-table4.csv`（需含 `D_mm`、`S_mm` 列）以及 `t3-20801-tableB1.csv`（需含 `标准`、`牌号` 及 `许用应力_<温度>` 列）。
2. 在「管道」页面右上角点击 **「标准表」** 按钮拖入或选择文件，程序采用版本化目录切换并自动校验表头与行数，校验通过后**立即生效（无需重启）**。列名拿不准时，弹窗里有「下载 CSV 模板」（`samples/pipe-standards-template/`，只有表头与 2 行虚构数值，不能直接导入）与「复制填写提示词」两个入口。
3. 详细的国标页码索引见 [`docs/pipe-standards-index.md`](docs/pipe-standards-index.md)；也可使用 [`docs/pipe-standards-extract-prompt.md`](docs/pipe-standards-extract-prompt.md) 中的提示词辅助提取国标表格。
</details>

<details>
<summary><strong>4. 为什么泵页面的参数或 NPSHₐ 显示为 `—`？</strong></summary>

- **整页为空**：可能是早期版本读取的旧快照，重新读取工况即可（或运行 `python -m tools.repair_cases --apply` 基于历史原始值重算）。
- **仅 $\text{NPSH}_a$ 为空**：计算需要进口流股的饱和蒸气压 $p_v$（默认读取泡点压力 `PBUB`）。可在表格中手动填入（支持同模型一键沿用上一工况），或在 Aspen 中新建 `pv` 物性组添加 `PL`、`PBUB` 并加入流股报告输出后重跑重读（详见 [`docs/pump-selection-plan.md`](docs/pump-selection-plan.md) §3.6）。
- **进口为两相流**：汽蚀余量计算公式前提不成立，系统会自动跳过计算并在悬浮提示中说明原因。
</details>

<details>
<summary><strong>5. 为什么管路壁厚比承压公式算出来的值更厚？</strong></summary>

程序在按 GB/T 20801.1-2025 6.6.1.2 计算承压壁厚并叠加腐蚀裕量与负偏差后，还会套用**工艺最小壁厚下限**（按施工刚度分档，非标准值：`DN10–25` 取 `2.0 mm`、`DN32–100` 取 `3.0 mm`、`DN125–150` 取 `3.5 mm`、`DN200–300` 取 `4.5 mm`、`DN350–600` 取 `5.5 mm`、`DN700–1000` 取 `10 mm`）。例如 1.0 MPa 下的 DN15 管道纯承压壁厚仅约 0.07 mm，属于仪表管规格，常规工艺管道无法焊接成型。在页面勾选「显示计算过程」可逐列查看承压厚度、所需厚度与最小壁厚下限。
</details>

<details>
<summary><strong>6. 其他常见问题（自动选材、默认流速、不收敛模型）</strong></summary>

- **会自动选材质吗？** 不会。介质腐蚀性受浓度、微量杂质（如氯离子 ppm）与温度影响极大，工具仅依据你配置的 `data/config/piping-classes.json` 按流股名前缀与介质代号匹配材质与腐蚀裕量（未配置时默认按 `S30408` 计算）。可选牌号以你导入的表 B.1 为准 —— 表里有哪些牌号，下拉里就能选哪些，不再限于内置的 5 个。
- **默认流速能改吗？** 可以，在「管道」页顶部参数条修改后实时生效（默认流速：液体 `1.5 m/s`、气体 `15 m/s`、两相 `8 m/s`、泵入口 `0.8 m/s`）。
- **不收敛模型能读吗？** 可以。数据照常入库并在顶部横幅标黄/标红警告，统计与多工况对比中默认隔离，同时完整保留报错原文与受波及流股标记。
</details>
