# model/ — Aspen 模型与运行文件

这个文件夹专门放 Aspen 相关的东西,让项目根目录保持干净。

## 为什么要有这个文件夹

Aspen Plus 会把**运行中间文件**写在 `.apw` 所在的目录里,文件名是 `_<运行ID>.*`
(`_3934gsr.inm`、`.his`、`.jnl`、`.sor`……),而且每次仿真都会重新生成一批。
如果模型放在项目根目录,根目录就会被这些文件淹掉。

→ **把模型放进 `model/`,运行文件就只会落在 `model/` 里。**

## 文件说明

| 文件 | 是什么 | 要不要留 |
| --- | --- | --- |
| `ASPEN 全流程模拟.apw` | 模型本体(用户数据) | ✅ 留 |
| `ASPEN 全流程模拟.bkp` | 上次运行结果的备份(含收敛解) | 建议留,便于回滚 |
| `.ads` / `.appdf` / `.his` / `.def` / `.for` | Aspen 自动生成的伴随文件 | 可留可删,删了下次运行会重建 |
| `_<运行ID>.*` | 运行中间文件(出现在这里说明跑过) | 可随时删 |

## 使用约定

1. **从这里打开模型**:双击 `ASPEN 全流程模拟.apw`,不要在项目根目录另存一份,否则运行文件又会漏到根目录。
2. `.apw` / `.bkp` / 运行中间文件都**不进 Git**(见根目录 `.gitignore`),这个文件夹只保留本 README。
3. 想清理运行记录:关掉 Aspen,删除 `_*.*` 即可,不会影响模型。
