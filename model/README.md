# model/ — 放你的 Aspen 模型

这个文件夹给 Aspen 模型及其运行文件用,让项目根目录保持干净。仓库里只有本 README,
模型本身已写入 `.gitignore`,不会被提交。

## 为什么单独放一个文件夹

Aspen Plus 会把**运行中间文件**写在 `.apw` 所在目录,文件名形如 `_<运行ID>.*`
(`.inm`、`.his`、`.jnl`、`.sor` 等),而且每次仿真都会重新生成一批。
模型放在项目根目录,根目录就会被这些文件淹掉;放进 `model/`,它们就只落在 `model/` 里。

## 使用方式

1. 把要读取的 `.apw` 放进这个文件夹,并从这里双击打开。
2. 不要另存一份到项目根目录,否则运行文件又会漏到外面。
3. 想清理运行记录:关掉 Aspen,删除 `_*.*` 即可,不会影响模型。

## 文件说明

| 文件 | 是什么 | 要不要留 |
| --- | --- | --- |
| `*.apw` | 模型本体 | ✅ 留 |
| `*.bkp` | 运行结果的备份(含收敛解) | 建议留,便于回滚 |
| `.ads` / `.appdf` / `.his` / `.def` / `.for` | Aspen 自动生成的伴随文件 | 可留可删,删了下次运行会重建 |
| `_<运行ID>.*` | 运行中间文件(出现在这里说明跑过) | 可随时删 |

> 所有 `*.apw`、`*.bkp` 与运行中间文件都不进 Git,这个文件夹可以放任意多个模型。
