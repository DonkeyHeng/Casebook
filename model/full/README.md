# model/full/ — 放规模更大的 Aspen 模型

`model/` 的子目录,用于放**流股更多、规模更大的全流程模型**,让这类模型的运行文件集中落在一处,
不和精简模型混在同一个目录里。仓库里只有本 README,模型与运行文件全部写入 `.gitignore`,不会被提交。

## 约定

- `*.apw`、`_<运行ID>.*`、`*.ads` 等都不进 Git
- 从本文件夹双击打开模型,不要另存到项目根目录或 `model/` 根下
- 大模型读取更慢(百条流股约十几到几十秒),读取时页面会有进度条

## 和 `model/` 根目录的区别

用法完全相同,只是按模型规模分开存放,方便同时保留一份精简模型和一份全流程模型。
想只用一个目录也可以,把模型都放进 `model/` 根下即可 —— 程序不按目录名找模型,
读哪个模型由页面上的选择决定。
